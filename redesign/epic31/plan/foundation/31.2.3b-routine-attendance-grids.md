# [31.2.3b] ui — Routine grid, routine agenda and attendance month grid: readable times, kit look, MonthGrid-style days

## Goal
`RoutineGrid`, `RoutineAgenda` and `AttendanceMonthGrid` look like their page mockups and speak the
D5/D7 formats: times read `সকাল ৮:০০ – সকাল ৮:৪০`, never `08:00:00` (B21); the agenda's selected day is a
card with a line-tab day switcher; the attendance month grid has the shared `MonthHeader`, today ring,
selected fill and status pills like `MonthGrid`. All new props are optional — no route changes in wave 2.
(Split from the old 31.2.3; 31.2.3a owns `calendar/**`.)

## Steps
1. **Read first**: the two specs, exactly — `PLAN/pages/routines/routines_sectionId/mockup.html`
   (grid: `grep -n "<thead" -A12`), `PLAN/pages/routines/routines_my/mockup.html` (agenda, lines ~150-200),
   `PLAN/pages/portal/portal_attendance/mockup.html` (month grid, lines ~90-135). The shared requests
   that asked for these looks are in `PLAN/kit/ALL-SHARED-REQUESTS.raw.md` (lanes routines, portal).
   Kit classes in the mockups that are physical (`text-left`, `pl-`) are written logical here
   (`ui/eslint.config.mjs:76-79`).
2. **Times (B21)** — in both routine components `const config = useRegionConfig()` (`../i18n`), and
   every time goes through `formatTime(value, config)` (`../utils`): `routine-grid.tsx:200`
   `{period.starts_at}–{period.ends_at}` and `routine-agenda.tsx:75` `{item.startsAt}–{item.endsAt}`.
   Separator is space, en dash, space.
3. **`RoutineGrid`** (kit look, request routines_sectionId):
   - `<table>`: drop `min-w-[640px]`; `<thead className="bg-muted text-label text-text-secondary">`, every
     `th` `h-10 border-b border-border-subtle font-medium` (`px-4` for the period column, `px-2` for days).
   - Row header `th scope="row"`: `w-52 border-b border-border-subtle px-4 py-2 text-start align-top font-normal`
     holding `<span className="block font-medium">{t('agenda.periodLabel', { sequence: period.sequence })}</span>`
     over `<span className="block whitespace-nowrap text-caption text-text-secondary">{formatTime(start)} – {formatTime(end)}</span>`.
   - Break row: `td` `h-8 bg-muted px-4 text-caption text-text-secondary` with `{name} · {start} – {end}`
     (drop `text-center text-xs`).
   - Cell button classes: base `flex min-h-14 w-full flex-col items-start gap-0.5 rounded-md border px-2 py-1.5 text-start outline-none focus-visible:ring-2 focus-visible:ring-ring focus-visible:ring-offset-2`;
     filled `border-border-subtle bg-surface` with subject `font-medium` + teachers `text-caption text-text-secondary`;
     empty `border-dashed border-border-subtle text-text-secondary` with `<PlusIcon className="size-3.5" aria-hidden="true" />` + `t('grid.emptyCell')` ("খালি");
     warning adds `<TriangleAlertIcon className="size-3.5" aria-hidden="true" />` before the subject (keep the
     violation/warning tone classes and `data-state`); recurrence `text-caption` (drop `text-[10px] uppercase`, `bg-card`, `text-xs`).
   - Each cell `aria-label`: filled `t('routine.cellLabel', { ns: 'common', weekday: weekdayLabels[weekday], period: periodLabel, subject: cell.subjectLabel, teachers: cell.teacherLabels.join(', ') })`,
     empty `t('routine.cellLabelEmpty', { ns: 'common', weekday, period })` (the component's first namespace
     stays `routines`, so pass `ns` explicitly — same rule as 31.2.11).
   - Keep the `md:hidden` "too narrow" paragraph (`text-text-secondary`, drop `text-sm`), keyboard handling, refs, `data-state`.
4. **`RoutineAgenda`** (kit look, request routines_my; also rendered by `/portal/routine`):
   - Day switcher stays the hand-rolled `role="tablist"` (no Radix `Tabs` — there are no panels to
     `aria-controls`), restyled as the kit line tabs: list `flex overflow-x-auto border-b border-border-subtle [scrollbar-width:none]`;
     tab `inline-flex h-11 shrink-0 items-center border-b-2 border-transparent px-3 whitespace-nowrap text-text-secondary hover:text-text-primary md:h-10`,
     selected `border-primary font-semibold text-primary`. Text: today → `t('agenda.todayLabel')`, other days
     `${day.weekdayLabel} ${formatNumber(Number(day.date.slice(8, 10)), config)}`.
   - Selected day (and each day in week view) in a card `rounded-lg border border-border-subtle bg-surface p-4 shadow-e1 md:p-5`:
     header `flex items-start justify-between gap-3` → `<h2 className="text-h3">{formatWeekday(day.date, config)}, {formatDate(day.date, config)}</h2>`
     + `<p className="text-text-secondary">{t('routine.periodCount', { ns: 'common', count: day.items.length })}</p>`;
     the week toggle moves into the selected-day card header: outline `Button` `h-11 md:h-8` with
     `CalendarDaysIcon` (keep `aria-pressed` and the two labels).
   - Rows `ul.divide-y.divide-border-subtle`, row `flex items-start gap-4 py-3`: time column `w-24 shrink-0 md:w-28`
     (`<p className="font-medium">{formatTime(startsAt)}</p><p className="text-caption text-text-secondary">{t('routine.until', { ns: 'common', time: formatTime(endsAt) })}</p>`),
     then subject `font-medium` (`line-through text-text-secondary` when cancelled) and caption
     `text-caption text-text-secondary` = `[sectionLabel, periodLabel, roomLabel].filter(Boolean).join(' · ')`;
     cancelled → `<StatusBadge tone="neutral" label={t('agenda.cancelledLabel')} />`, covering →
     `<StatusBadge tone="info" label={item.coveringForLabel} />` (replace the two hand-made pills, D27).
   - Off day: the reason as `text-text-secondary` inside the card; empty day `t('agenda.emptyDay')` the same way.
5. **`AttendanceMonthGrid`** (old 31.2.3 step 7 + request portal_attendance):
   - Props (all optional, backward compatible): `today?: string` (default `toIsoDate(new Date())`),
     `selectedDate?: string`, `onMonthChange?: (month: string) => void`. When `onMonthChange` is set,
     render `<MonthHeader label={formatMonth(month, config)} onPrevious onNext onToday />` above the grid
     (prev/next month strings with `Date.UTC`, like `buildGridDays`; Today → `onMonthChange(today.slice(0, 7))`
     and `onSelectDay` of today's cell when it exists).
   - Caption: `formatMonth(month, config)`; it becomes `sr-only` when the header is rendered, visible
     (`text-h3`) otherwise. Delete `MONTH_KEYS` (`:136-149`) and the `attendanceGrid.caption` call — the
     `portal.json` keys go unused (cleanup is the portal page ticket's; do not edit `portal.json`).
   - Frame and cells per the mockup: wrapper `overflow-hidden rounded-lg border border-border-subtle bg-surface shadow-e1`;
     weekday band `bg-muted text-label text-text-secondary`, cells `h-8`; keep `<table>` semantics and every
     test id. Day cell content = `<span className="flex size-7 items-center justify-center rounded-full text-label">{renderDigits(String(dayOfMonth), config.numerals)}</span>`
     + a status pill `flex size-5 items-center justify-center rounded-full` with the state's tone classes and
     its icon `size-3.5` (no pill when not marked — drop the dashed "not marked" box). Today: span gets
     `font-semibold text-primary ring-2 ring-primary ring-inset` and the cell `aria-current="date"`;
     selected: cell ground `bg-secondary`, span `bg-primary font-semibold text-primary-foreground`;
     not a working day: ground `bg-muted`. Keep the `after:-inset-2` hit-area extension and the popover.
   - Legend: one `ul` row `flex flex-wrap gap-x-4 gap-y-2 border-t border-border-subtle p-3 text-caption text-text-secondary md:px-4`
     with `aria-label={t('attendanceGrid.legendTitle')}` inside the frame (drop the separate `h3`).
