from `@biddaloy/ui/components` or `@biddaloy/ui/shells`, renders something usable, and every new
shared string is in `common.json` (en + bn). After this ticket (and 31.1.2b) no wave-2 ticket edits
`ui/src/components/index.ts`, `ui/src/shells/index.ts`, `ui/src/utils/index.ts` or
`ui/src/i18n/locales/*/common.json`.

`common.json`) and **31.1.2b** (formatter signatures + `toIsoDate` + the three B19 call sites +
`utils/index.ts`). Both are wave 1, file-disjoint with each other and with 31.1.1; 31.1.2b runs first in the same lane.

## Rules for every stub
- File header: one short doc comment naming the decision (Dn) and "filled in by 31.2.x".
- Props exactly as below. `className?: string` is allowed extra where noted.
- Logical Tailwind classes only (`ps-/pe-/ms-/me-/start-/end-/text-start/text-end`): the
  `logical-properties/no-physical-direction-classes` lint rule covers `src/components/**` and
  `src/shells/**` (`ui/eslint.config.mjs:76-79`).
- Strings only through `const { t } = useTranslation('common')` (`../i18n`) — never a literal.
- Numbers on screen through `formatNumber(n, useRegionConfig())` (`../utils/number`).
- Icons from `lucide-react` (named imports, e.g. `ChevronLeftIcon` form as used in `detail-shell.tsx`).
- No stories or tests here — 31.2.13 adds stories; each wave-2 owner adds tests.
