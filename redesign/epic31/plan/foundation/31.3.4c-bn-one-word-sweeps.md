# [31.3.4c] i18n — one word per thing in Bangla: শ্রেণি, শাখা, কর্মী, উপস্থিতি, দফা, নম্বর, ভূমিকা, প্রতিবেদন

## Goal
Every Bangla locale file uses one word per thing (D32, glossary 31.3.4a §A): no grade-sense "ক্লাস", no "সেকশন", "স্টাফ", "হাজিরা", "ব্যাচ", score-sense "মার্ক", role-sense "রোল", "রিপোর্ট" — so the wave-4 page tickets start from consistent words.

**Lane rule:** third and last ticket of the wave-3 "locales" lane (31.3.4a → 31.3.4b → 31.3.4c). Split out of 31.3.4b (its old section B6) to keep each ticket one afternoon. bn files only — English already uses one word per thing.

## Files
- `ui/src/i18n/locales/bn/{attendance,auditLogs,calendar,examTemplates,exams,examsTemplateField,fees,fines,portal,routines,staff,syllabus,staffAttendance}.json` (changed) + any other bn file the sweeps hit, except `nav.json` / `common.json` (31.3.4a did those). `myClass.json` (new in PR #1407) was checked against every sweep: its only hit is the roll-number "রোল" exception below, so it is not edited.
- Any unit test / e2e spec that hard-codes a changed Bangla string (step 4).
Size note: ~15–20 bn JSON files; every edit is a word swap, no code.

## Steps
1. **Read first:** 31.3.4a §A (glossary) and its "Who applies which row" note; 31.3.4b B5 (rows already applied — do not re-touch those keys).
2. Grammar endings to keep: ক্লাস→শ্রেণি, ক্লাসের→শ্রেণির, ক্লাসে→শ্রেণিতে, ক্লাসগুলোর→শ্রেণিগুলোর; সেকশন→শাখা, সেকশনের→শাখার, সেকশনে→শাখায়; ব্যাচ→দফা, ব্যাচের→দফার, ব্যাচে→দফায়; স্টাফ→কর্মী, স্টাফদের→কর্মীদের. Keep `{{placeholders}}` and plural suffixes.
3. Run each sweep in the table below with `rg -n "<word>" ui/src/i18n/locales/bn --glob '!nav.json' --glob '!common.json'` and fix each hit by its rule. Read every "মার্ক" and "রোল" hit — only the score / user-role senses change.
4. `rg -n "<old Bangla value>" client-admin/src ui/src e2e --glob '*.{ts,tsx}'` for each changed value; a test asserting the old literal reads it through `t()` / `e2e/i18n.ts` instead.
5. `yarn workspace @biddaloy/ui check:i18n`, `yarn test:frontend run`.
