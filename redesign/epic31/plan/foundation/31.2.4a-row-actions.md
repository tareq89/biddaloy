# [31.2.4a] ui — DataTable: icon row actions (`RowActions`) with tooltips

## Goal
`DataTable` takes an optional `rowActions` prop that renders icon buttons with a tooltip (desktop) or labelled buttons (card mode) in a last "কাজ" column. Pages that still pass their own text-link `actions` column keep working unchanged.

## Files
- `ui/src/components/row-actions.tsx` (stub from 31.1.2 → filled) — `RowActions`, `RowAction`, `RowActionIntent`, `RowActionsProps`, plus the internal `RowActionsLayoutContext` (exported from this file only, not from `index.ts`)
- `ui/src/components/tooltip.tsx` (changed) — kit look for `TooltipContent`
- `ui/src/components/data-table.tsx` (changed) — `rowActions` prop, appended actions column, layout context
- `ui/src/components/data-table-cards.tsx` (changed) — actions wrapper grows so labelled buttons can share the row
- `e2e/pages/list-shell.ts` (changed) — `clickRowAction()` helper
- `ui/src/components/row-actions.test.tsx` (new)
- `ui/src/components/data-table.test.tsx` (changed) — new `rowActions` cases

## Steps
1. **Read first**: `patterns.md` §4 "RowActions" (prop shape, the intent → icon → colour table, desktop and phone classes) and `conflicts.md` C12 (phone shows labels). Cite D19.
2. **`row-actions.tsx`** — implement exactly the `patterns.md` types:
   ```ts
   export type RowActionIntent = 'view' | 'edit' | 'delete' | 'remove' | 'print' | 'download' | 'pay'
     | 'approve' | 'reject' | 'duplicate' | 'archive' | 'restore' | 'send';
   export interface RowAction { intent: RowActionIntent; label: string; onClick?: () => void;
     to?: string; allowed?: boolean; icon?: React.ReactNode;
     'data-focus-anchor'?: string }   // final since 31.1.2a; CONTRACT Addendum 7
   export interface RowActionsProps { actions: readonly RowAction[] }
   export const RowActionsLayoutContext = React.createContext<'icons' | 'labelled'>('icons');
   ```
   - One `INTENTS` map `Record<RowActionIntent, { icon: LucideIcon; tone: string }>` from the patterns table. lucide-react names (all verified present in lucide-react 1.45): `Eye`, `Pencil`, `Trash2`, `CircleMinus`, `Printer`, `Download`, `HandCoins`, `CircleCheck`, `CircleX`, `Copy`, `Archive`, `ArchiveRestore`, `Send`; More = `EllipsisVertical`. Tone classes exactly: view/print/download/duplicate/archive `text-text-secondary`; edit/restore/send `text-primary`; delete/remove/reject `text-destructive`; pay/approve `text-status-paid-fg`.
   - `const visible = actions.filter(a => a.allowed !== false)` (hidden, never disabled). If `visible.length <= 3` all are buttons. Otherwise: `danger = visible.filter(a => a.intent === 'delete' || a.intent === 'remove')`, `rest = visible minus danger`; buttons = `rest.slice(0, 3)`; menu = `rest.slice(3)`, then `<MenuSeparator />` (only when both parts are non-empty), then `danger`. Render nothing when `visible` is empty.
   - Read `const layout = React.useContext(RowActionsLayoutContext)`.
   - **`icons` layout (table)**: wrapper `<div className="flex items-center justify-end gap-1">`. Each action = `Tooltip` + `TooltipTrigger asChild` around an icon button with classes `inline-flex size-11 shrink-0 items-center justify-center rounded-md hover:bg-muted md:size-8` + tone, `aria-label={label}`, icon `size-4 aria-hidden`. `TooltipContent side="top"` shows `label`. Wrap the whole component in its own `<TooltipProvider delayDuration={300}>` — no app-wide provider exists (`TooltipProvider` is only mounted locally, e.g. `ui/src/components/attendance-month-grid.tsx:271`), and nested providers are allowed.
   - **`labelled` layout (cards, C12)**: wrapper `<div className="flex w-full items-center">`; each button `inline-flex h-11 min-w-0 flex-1 items-center justify-center gap-1.5 rounded-md text-label font-medium hover:bg-muted` + tone, icon + visible `<span className="truncate">{label}</span>`, no tooltip.
   - `to` set → render `<Link to={action.to}>` from `@tanstack/react-router` with the same classes (`app-shell.tsx:42` already imports `Link` in this package); otherwise `<button type="button" onClick>`. `icon` overrides the default glyph.
   - **Focus anchor** (shared request students; used by students, guardians, staff, surveys, ACR lists): copy `action['data-focus-anchor']` onto the rendered `<button>` / `<Link>` as `data-focus-anchor={…}` in both layouts (and on the `MenuItem asChild` link inside More). `useRouteFocus` (`ui/src/hooks/use-route-focus.ts:176,354`) already restores focus to `[data-focus-anchor="<id>"]` on Back — no other wiring.
   - More: `Menu` / `MenuTrigger asChild` / `MenuContent align="end"` / `MenuItem` / `MenuSeparator` from `./menu` (clone the overflow menu in `ui/src/shells/detail-shell.tsx:157-183`). Trigger = icon button (same classes as above, `text-text-secondary`), `EllipsisVertical`, `aria-label={t('actions.moreActions')}` — stays an icon in both layouts. Each item = icon (tone colour) + label; `onSelect` calls `onClick`, or for `to` use `MenuItem asChild` around a `Link`. Danger items `variant="destructive"`.
3. **`tooltip.tsx`** — `TooltipContent` passes `sideOffset={4}` (unless given) and merges `className={cn('rounded-md px-2 py-1 text-caption whitespace-nowrap shadow-e2', props.className)}` onto the primitive (keep `bg-foreground text-background` from `ui/src/primitives/tooltip.tsx:41`). 6. **`e2e/pages/list-shell.ts`** — add:
   ```ts
   /** A row action by its label key — works for an icon button (aria-label), a link, and an item in the row's More menu. */
   async clickRowAction(rowText: string, labelKey: string): Promise<void>
   ```
   Find `row(rowText).first()`; try `getByRole('button'|'link', { name: this.t(labelKey), exact: true })` inside it (`.or()`); if count is 0, click the row's `getByRole('button', { name: this.t('common.actions.moreActions') })` and then `this.page.getByRole('menuitem', { name: this.t(labelKey) })`. Same "wait for either, then decide" shape as `e2e/pages/detail-shell.ts` `clickAction`.

## Tests
- `ui/src/components/row-actions.test.tsx` (use `renderWithProviders` from `../test`, `locale: 'en'`, await `localeReady` like `data-table.test.tsx`):
  - 2 actions → 2 buttons named by `label`, no More button.
  - `allowed: false` → not in the DOM at all.
  - 5 actions incl. a `delete` → 3 icon buttons + More; delete is not among the 3; opening More shows the rest, the delete item last after a `separator`.
  - intent `edit` button has class `text-primary`; `delete` has `text-destructive`; `pay` has `text-status-paid-fg`.
  - `to` renders a `link` (wrap in a memory router as `ui/src/shells/use-detail-shell-tab.test.tsx` does); with `'data-focus-anchor': 'row-1'` the link has `data-focus-anchor="row-1"` (also in the `labelled` layout).
  - Inside `<RowActionsLayoutContext.Provider value="labelled">` the label text is visible (`getByText(label)`) and there is no tooltip.
  - hovering/focusing an icon button shows the tooltip text (`findByRole('tooltip')`).
  - axe clean (`toHaveNoViolations`, as in `detail-shell.test.tsx:195`).
