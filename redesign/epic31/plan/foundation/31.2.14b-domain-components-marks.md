# [31.2.14b] ui — marks & results components to kit look: MarksGrid, MarksStepper, ReportCard, MilestoneChecklist

## Goal
The marks-entry grid and phone stepper, the printed report card and the program milestone checklist use
kit tokens and tenant numerals (D6): values and full marks show `৫২ / ১০০`, a Bangla-keyboard teacher can
type `০–৯`, GPA reads `৪.৫০` via `formatNumber` (never `toFixed`), saved rows show a real icon, phone
buttons are 44 px with full words. No prop or callback signature changes; what is staged/saved stays
Latin-digit data.

## Steps
1. **Read first** — the specs: `PLAN/pages/marks/marks_examId_sectionId_subjectId/mockup.html:150-200`
   (grid; the phone stepper is in the same file's mobile part), `PLAN/pages/marks/results_examId_studentId/mockup.html`
   (report card numbers), `PLAN/pages/programs/programs_programId/mockup.html:203` (milestone rows). Requests: lanes
   marks, programs in `PLAN/kit/ALL-SHARED-REQUESTS.raw.md`. Digit helpers: `renderDigits`, `toLatinDigits`
   (`ui/src/utils/digits.ts`), `formatNumber` (`ui/src/utils/number.ts`, `{ decimals }` option — check its
   signature; 31.2.1b makes it return `—` for null).
2. **Numerals in both marks components** (`const config = useRegionConfig()`):
   - Input `value`: `renderDigits(cellValue.value ?? '', config.numerals)` for PRESENT values (ABSENT/EXEMPT
     labels unchanged).
   - Input `onChange`: normalise first — `const raw = toLatinDigits(event.target.value)` — then today's
     logic unchanged (`/^\d*\.?\d*$/`, `> full_marks`, `toStagedMark`). The ABSENT/EXEMPT branch strips with
     `/[^\d.]/g` **after** `toLatinDigits`. Staged/saved values stay Latin (data, D6).
   - `{{max}}` params (`marksGrid.fullMarks`, `marksGrid.cellMax`): pass `formatNumber(Number(component.full_marks), config)`
     (the server may send `"100.00"` as a string, which the i18n numeral formatter of 31.2.1b leaves alone).
   - Derived cells: `formatNumber(value, config)` when it is a number; `'—'` stays.
3. **`marks-grid.tsx`** — kit table (classes from the mockup; logical classes only):
   - wrapper `overflow-x-auto rounded-lg border border-border-functional bg-surface`; `table` `w-full border-collapse text-body`.
   - header row `bg-muted text-label text-text-secondary`; `th` `h-10 px-4 text-start font-medium`; sticky student
     `th`/`td` `bg-muted` / `bg-surface` (drop `bg-background`); full-marks line `block text-caption font-normal`.
   - `tbody` `divide-y divide-border-subtle` (drop each row's `border-b`); cells `px-4 py-1.5 align-top`.
   - Student cell: `<span className="flex h-8 items-center gap-2"><span className="w-6 text-end tabular-nums text-text-secondary">{roll}</span><span className="font-medium">{name}</span>{rowSaved && <CircleCheckIcon className="size-4 text-status-paid-fg" aria-label={t('marksGrid.rowSaved')} data-testid=… />}</span>`
     (replaces the "✓" glyph; keep the test id on the icon; roll via `renderDigits`).
   - Input `h-8 w-20 rounded-md border border-border-functional bg-surface px-2 text-end text-body tabular-nums text-text-primary`;
     failed `border-destructive`, pending `border-status-due-fg` (keep). Error line `text-caption text-destructive`.
   - Derived column `bg-muted text-end text-text-secondary`.
   - Empty (`students.length === 0`): `<EmptyState title={t('marksEntry.emptyTitle', { ns: 'common' })} explanation={t('marksGrid.empty')} />`
     (default `h2`, 31.2.8a) instead of the bare paragraph.
4. **`marks-stepper.tsx`**:
   - prev/next: default-size outline `Button`s (`h-11` on phone via `--control-h`; drop `size="sm"`), with
     `ChevronLeftIcon`/`ChevronRightIcon` (`rtl:rotate-180`); progress text `text-text-secondary` through
     `t('marksStepper.progress', { current, total })` (numbers interpolate in tenant digits after 31.2.1b).
   - student card `rounded-lg border border-border-subtle bg-surface p-4`; name `text-h3`, roll `text-text-secondary`;
     saved → `CircleCheckIcon size-4 text-status-paid-fg` as in the grid.
   - per component: label `text-label text-text-primary` + `text-text-secondary` full marks; input as the grid
     but `h-11 w-24 md:h-8`; absent/exempt buttons default size (drop `size="sm"`) with **full words**
     `t('marksEntry.absent', { ns: 'common' })` / `t('marksEntry.exempt', { ns: 'common' })` (first namespace stays
     `exams`); derived boxes `rounded-md bg-muted p-2`, label `text-label text-text-secondary`.
   - empty → the same `EmptyState` as the grid.
5. **`print/report-card.tsx`** (`const config = useRegionConfig()`; print routes render inside the app's
   provider — if the component can render without one, `useRegionConfig()` falls back to `REGION_BD_BN`):
   every number through `formatNumber`: `subject.obtained`, `subjectFullMarks(...)`, component `obtained` and
   full marks, `data.result.total_marks`, `data.result.position`, `program.achieved_count / milestone_total`,
   GPA `formatNumber(gpa, config, { decimals: 2 })` instead of `gpa.toFixed(2)` (`:155`, `:180`, `:236`, legend
   bands). `text-muted-foreground` → `text-text-secondary` everywhere (`:124`, `:132`, `:146`, `:158`, `:198`, `:230`).
   Keep the print layout and `labels` prop untouched.
6. **`programs/milestone-checklist.tsx`** (mockup `programs_programId:203`):
   - `ul` gets no gap; row button `flex min-h-11 w-full items-center gap-3 rounded-md px-2 text-start hover:bg-muted md:min-h-8`
     (both states).
   - Replace the `☑`/`☐` glyphs with the kit checkbox look: `<span aria-hidden="true" className="flex size-5 shrink-0 items-center justify-center rounded-sm border border-border-functional bg-surface">`;
     achieved → `border-0 bg-primary text-primary-foreground` with `<CheckIcon className="size-3.5" />`. Keep
     `role="checkbox"`, `aria-checked`, `data-milestone-id`, Space handling.
   - achieved meta `text-caption text-text-secondary` (drop `text-xs text-muted-foreground`); the caller passes
     `achievedOn` already formatted (`formatDate`) — say so in the prop doc.
   - Popover: remark `text-text-primary`; Undo = `Button variant="ghost"` with `RotateCcwIcon` (was an
     underlined red link, D29). Empty message `text-text-secondary`.
