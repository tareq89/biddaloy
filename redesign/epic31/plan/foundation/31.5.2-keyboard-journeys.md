## Steps
1. **Read first:** `e2e/keyboard/admission-reports.spec.ts:82-99` — the step "nav -> Admission reports, keyboard only" is the exact flow to clone (focus `<body>`, `Tab`, `tabUntilFocused(page, label, 150, { tag: 'a' })`, `Enter`, assert the `h1`). Helpers: `e2e/keyboard/keyboard-utils.ts` (`focusedText`, `tabUntilFocused`, `selectByTypeahead`). Labels come from `t()` in `e2e/i18n.ts` (bn is the default locale; plurals need the explicit `_one`/`_other` key). Every sidebar group is already expanded for specs by the login fixture (`e2e/fixtures/test.ts:46-62`), so no group toggle is needed. Login: `test.use(loggedIn('<role>'))` from `e2e/fixtures/test.ts`.
2. **Add two helpers to `keyboard-utils.ts`** (keyboard only, no mouse):
   - `openFromSidebar(page, label, max = 150)`: the body-focus trick from `admission-reports.spec.ts:86-90`, then `Tab`, `tabUntilFocused(page, label, max, { tag: 'a' })`, `Enter`, then `await expect(page.getByRole('heading', { level: 1, name: label })).toBeVisible()` — D16/D32: the `h1` text equals the nav label.
   - `expectPrimaryTaskOpensAndCloses(page, actionLabel, opened)`: `tabUntilFocused(page, actionLabel, 30, { tag: 'BUTTON' })` from the focused heading (header actions follow the `h1` in DOM order), remember the trigger with `page.locator(':focus')`, `Enter`, `await expect(opened).toBeVisible()` (a `getByRole('dialog', …)` or, for a full-page modal, its `h1`), `Escape`, `await expect(opened).toBeHidden()`, then `await expect(trigger).toBeFocused()` (focus returns to the trigger). A clean full-page modal closes on Escape without a discard prompt (D22). Pass `{ tag: 'A' }` through if the primary is a link.
3. **One spec per group, one `test()` per route** (isolated, no shared page state). Group tests by login role in `test.describe` blocks, each with its own `test.use(loggedIn(role))`. Role = the route's `role` in `e2e/route-manifest.json`. Each test: `page.goto('/dashboard')`, wait for its `h1`, `openFromSidebar`, then the primary task if the page has one, else Tab once from the heading and assert the focused element is inside `main` (`await expect(page.locator('main :focus')).toHaveCount(1)`) — reachability without a primary.
4. **The 31 routes** (computed on `main@1bb014b4` — after PR #1407 — against every `page.goto`, `toHaveURL` and `nav.items.*` use in `e2e/keyboard/`; nav keys from `client-admin/src/nav-tree.ts`; entity labels use `t('common.entities.<entity>_other')`, the form `e2e/keyboard/organisation-structure.spec.ts:182` uses). "Primary today" is the current button key — after wave 4, take the label of the page's `PageHeader` primary; if a page has no primary, use the reachability check.
