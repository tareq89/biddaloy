# [31.3.1] client-admin — staff layout: one icon per nav item, bottom bar per role, phone top bar

## Goal
The staff layout passes every nav item its own distinct icon, gives each staff role its own four bottom-bar cells, and fills the new `AppShell` phone top bar (school name · search · bell · account) using the wave-2 props, so the staff shell matches `starter.html` at 390 px and 1440 px. The sidebar also gains the five pages that exist but had no item (`/payments`, `/marks`, `/results`, `/routines/review`, `/routines/substitutions`) and drops "ফি" → `/fees`, which becomes a redirect (D40).

## Decisions settled here
- The account menu has **no "profile — coming soon" row** (step 6): a placeholder for an unbuilt page is D9-style noise; "My account" is the security page for staff.
- **Notifications are wiped on sign-out** (shared-browser privacy). 31.2.11 already purges every stored `notifications:v1:*` key in `clearAuthState()`; the sign-out row here calls the existing sign-out path and adds nothing. The test below proves it end to end.
