# [31.1.2b] ui — scaffold: formatter signatures, `toIsoDate`, and move the three data uses of `formatDate` off it

## Goal
`toIsoDate` exists and the three places that use `formatDate` output as **data** (B19) use it
instead, so 31.2.1 can turn `formatDate` into the long display form without breaking a URL, a
search param or a typed date. The new formatter names are exported with their final signatures
(numeric placeholder bodies that 31.2.1 replaces). Nothing on screen changes.

## Steps
1. **`date.ts` — `toIsoDate` (final).** Below `formatDateTime`:
   ```ts
   /** `YYYY-MM-DD` from the date's local calendar fields, Latin digits always — for URLs, search
    * params, API bodies and exports (D5). Never for display; use `formatDate`. */
   export function toIsoDate(date: Date): string {
     const y = String(date.getFullYear()).padStart(4, '0');
     const m = String(date.getMonth() + 1).padStart(2, '0');
     const d = String(date.getDate()).padStart(2, '0');
     return `${y}-${m}-${d}`;
   }
   ```
2. **`date.ts` — new display formatters, final signatures, placeholder bodies** (31.2.1 rewrites the
   bodies of `formatMonth`, `formatTime`, `formatDateRange`; keep the signatures). All return `'—'`
   for `null`/`undefined`/`''`/unparseable input and never throw:
   ```ts
   export function formatMonth(value: Date | string | null | undefined, config: RegionConfig): string
   // placeholder: Date → `${YYYY}-${MM}`; string → first 7 chars if /^\d{4}-\d{2}/; renderDigits(…, config.numerals)

   export function formatMonthName(month: number, config: RegionConfig): string   // month 1–12
   // final already: new Intl.DateTimeFormat(config.locale, { month: 'long', timeZone: 'UTC' }).format(Date.UTC(2000, month - 1, 1))

   export function formatTime(value: Date | string | null | undefined, config: RegionConfig): string
   // placeholder: string matching /^(\d{1,2}):(\d{2})/ → `HH:mm`; Date → local `HH:mm`; renderDigits

   export function formatWeekday(value: Date | string | null | undefined, config: RegionConfig): string
   // final already: Date → Intl weekday 'long' (local); 'YYYY-MM-DD…' string → Intl weekday 'long' of Date.UTC(y, m-1, d) with timeZone 'UTC'

   export function formatDateRange(from: Date | string, to: Date | string, config: RegionConfig): string
   // placeholder: `${formatDate(a, config)} – ${formatDate(b, config)}` where a string goes through parseServerDate (wrap in try/catch → '—')
   ```
   `Intl` belongs here: `ui/src/utils` is the shared formatter layer (`ui/src/utils/index.ts:2`), and
   `boundary/no-raw-intl` only runs in the client apps (`ui/eslint-rules/component-boundary.mjs:1-11`).
