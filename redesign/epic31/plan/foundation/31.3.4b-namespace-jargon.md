# [31.3.4b] i18n — jargon renames across feature namespaces (en + bn)

## Goal
Every feature namespace uses the glossary from 31.3.4a §A: no "Dues queue", "batch", "run", "commit", "slug", "step-up approval", "recurring schedule", "curriculum preset", "grid", "wallet", "token" on guest pages, "প্রতিনিধিত্ব", "ভর্তি গ্রহণ", "উত্তরণ", "রান" — and each page title equals its new nav label (D16). The bn "one word per thing" sweeps (`শ্রেণি` not `ক্লাস`…) are split out to 31.3.4c, which runs next.

**Lane rule:** runs right after 31.3.4a and before 31.3.4c in the same "locales" lane (31.3.4a → 31.3.4b → 31.3.4c); those three are the only wave-3 tickets on `ui/src/i18n/locales/**`. Page tickets in wave 4 own these namespaces afterwards (D3) and apply the same glossary to anything they add.

## Files
- `ui/src/i18n/locales/{en,bn}/{fees,promotions,admission-staff-intakes,admission-staff-applicants,routines,curriculumPreset,presetReset,presetWarning,examTemplates,exams,platform,settings,communications,auditLogs,auth,backup,payments,portal,reports,students,printEditor,printPreview,printTemplates,calendarImport,guardians,fines,bulkImport}.json` (changed) — B5.
- Any unit test / e2e spec that hard-codes a changed string (step 5).
Size note: ~54 JSON files, but every edit is a string swap listed below; no code.

## Steps
1. **Read first:** 31.3.4a §A (the glossary) and B1 (the new nav labels); `PLAN/kit/DECISIONS.md` D16, D32, D34.
2. Edit en and bn together; keep `{{placeholders}}` and plural suffixes. Where a row says "→ term", change only that term inside the existing sentence and fix the grammar around it (Bangla endings: ক্লাস→শ্রেণি, ক্লাসের→শ্রেণির, ক্লাসে→শ্রেণিতে, ক্লাসগুলোর→শ্রেণিগুলোর; সেকশন→শাখা, সেকশনের→শাখার, সেকশনে→শাখায়; ব্যাচ→দফা, ব্যাচের→দফার, ব্যাচে→দফায়).
3. **Page titles follow the nav label (D16).** For every label changed in 31.3.4a B1, find the page's h1/title key in its own namespace (`rg -n "<old en value>" ui/src/i18n/locales/en/<ns>.json`) and set it to the same new en/bn value. Known ones are in B5 (`fees.dues.title`, `fees.schedules.title`, `promotions.list.title`, `admission-staff-intakes.list.title`, `curriculumPreset.title`, `routines.substitutionsPage.title`); also look for the titles of `/attendance/register`, `/audit-logs`, `/reports/collections`, `/fees/generate`, `/print-templates`, `/reports/printables`, `/programs`, `/routines`, `/exams/templates`, `/staff/teaching-assignments`, `/analysis`, `/grading-scales`, `/attendance/staff`, `/admissions/reports`. Report any you could not find.
4. Run `yarn workspace @biddaloy/ui check:i18n`, `yarn test:frontend run`; fix any test asserting a changed literal by reading it through `t()` / `e2e/i18n.ts`.
