# [31.2.6] ui — Dialog sizes and padding, ConfirmDialog, FullPageShell

Dialogs come in `sm`/`md`/`lg` with 20 px padding and no tinted footer band; `ConfirmDialog` is the one place a red filled button lives; `FullPageShell` is the full-page modal (sticky title bar with a big Close, centred body, sticky footer, asks before discarding) that works both as a chromeless route and as a search-param overlay on a host route.

5. **`full-page-shell.tsx`** — props exactly as `patterns.md`:
   ```ts
   export interface FullPageShellAction { label: string; onClick: () => void; busy?: boolean; disabled?: boolean }
   export interface FullPageShellProps { title: string; onClose: () => void; dirty?: boolean;
     size?: 'form' | 'wide'; primary: FullPageShellAction;
     secondary?: { label: string; onClick: () => void }; children: React.ReactNode }
   ```
   Build it on Radix Dialog (`import { Dialog as DialogPrimitive } from 'radix-ui'` — same import as `primitives/dialog.tsx:4`), always open. That one choice gives the focus trap, scroll lock, `aria-modal`, inert background, and a portal that covers the app shell — so the sidebar, top bar and bottom bar are hidden in **both** modes below without either layout knowing (D14: bottom bar hidden inside a full-page modal).
   ```tsx
   const [confirming, setConfirming] = React.useState(false);
   useWarnUnsavedChanges(dirty === true);                 // ./use-form-shell — beforeunload only
   const requestClose = () => (dirty ? setConfirming(true) : onClose());
   const width = size === 'wide' ? 'max-w-5xl' : 'max-w-3xl';
   <DialogPrimitive.Root open onOpenChange={(open) => { if (!open) requestClose(); }}>
     <DialogPrimitive.Portal>
       <DialogPrimitive.Content data-slot="full-page-shell" aria-describedby={undefined}
         onEscapeKeyDown={(e) => { e.preventDefault(); requestClose(); }}
         className="fixed inset-0 z-50 flex flex-col overflow-y-auto overscroll-contain bg-bg outline-none">
         <header className="sticky top-0 z-30 border-b border-border-subtle bg-surface">
           <div className="flex h-14 items-center justify-between gap-4 px-4 md:h-16 md:px-6">
             <DialogPrimitive.Title asChild><h1 className="truncate text-h2 md:text-h1">{title}</h1></DialogPrimitive.Title>
             <Button variant="outline" className="h-11 shrink-0" onClick={requestClose}><XIcon aria-hidden="true" />{t('actions.close')}</Button>
           </div>
         </header>
         <div className={cn('mx-auto w-full flex-1 space-y-6 px-4 py-4 md:px-6 md:py-6', width)}>{children}</div>
         <footer className="sticky bottom-0 z-30 border-t border-border-subtle bg-surface">
           <div className={cn('mx-auto flex w-full items-center justify-between gap-2 px-4 py-3 md:px-6', width)}>
             {secondary ? <Button variant="outline" className="h-11" onClick={secondary.onClick}>{secondary.label}</Button> : <span />}
             <Button className="h-11" loading={primary.busy} disabled={primary.disabled} onClick={primary.onClick}>{primary.label}</Button>
           </div>
         </footer>
         <ConfirmDialog open={confirming} onOpenChange={setConfirming} tone="danger"
           title={t('fullPage.discardTitle')} description={t('fullPage.discardDescription')}
           confirmLabel={t('fullPage.discardConfirm')} cancelLabel={t('fullPage.keepEditing')}
           onConfirm={() => { setConfirming(false); onClose(); }} />
       </DialogPrimitive.Content>
     </DialogPrimitive.Portal>
   </DialogPrimitive.Root>
   ```
   The body is a `<div>`, not `<main>`: in overlay mode the host page's `<main>` is still in the DOM.
   The primary button sits outside the page's `<form>`; a page submits with `onClick: form.handleSubmit(save)` (react-hook-form) — no extra prop.
6. **`useCloseFullPage`** (same file) — already final from 31.1.2a (exported from `@biddaloy/ui/shells`); keep the body below unchanged and add its tests here. "Closing returns to where the user came from" (D22):
   ```ts
   export function useCloseFullPage(fallback: () => void): () => void {
     const router = useRouter();                           // @tanstack/react-router
     return React.useCallback(() => (router.history.canGoBack() ? router.history.back() : fallback()), [router, fallback]);
   }
   ```
   `canGoBack()` (`@tanstack/history` 1.162) is false for the first entry of the app session, so a deep link or a new tab falls back instead of leaving the app.
7. **How a page uses it** — write both in the file's doc comment:
   - **Own route, chromeless** (`staticData: { chromeless: true }` — `_staff.tsx:171` reads it and `:314` then renders the route without `AppShell`; today `print/preview.tsx:34` and `print-templates/$templateId.edit.tsx:12`):
     ```tsx
     function PrintPreviewPage() {
       const navigate = useNavigate();
       const close = useCloseFullPage(() => void navigate({ to: '/print-templates' }));
       return <FullPageShell title={t('preview.title')} onClose={close} size="wide"
         primary={{ label: t('preview.print'), onClick: () => window.print() }}>…</FullPageShell>;
     }
     ```
   - **Overlay on a host route** (no route of its own — e.g. "add student" on `/students`): the host route's `validateSearch` gains one optional key; the page opens it by setting the key and renders the shell when it is set. The address bar shows `/students?add=1`, Back closes it, refresh reopens it.
     ```tsx
     // students/index.tsx validateSearch: z.object({ …, add: z.literal(1).optional() })
     const search = Route.useSearch(); const navigate = Route.useNavigate();
     const openAdd = () => void navigate({ search: (prev) => ({ ...prev, add: 1 }) });
     const closeAdd = useCloseFullPage(() => void navigate({ search: ({ add: _add, ...rest }) => rest, replace: true }));
     {search.add === 1 && <FullPageShell title={t('add.title')} onClose={closeAdd} dirty={form.formState.isDirty}
       primary={{ label: t('add.save'), onClick: form.handleSubmit(save), busy: create.isPending }}
       secondary={{ label: t('common:actions.cancel'), onClick: closeAdd }}>…</FullPageShell>}
     ```
     The host route stays a normal (not chromeless) route; the Radix portal covers its chrome.
