# [31.2.3a] ui — Calendar: MonthGrid with month header + today + selected day, DayPanel, AgendaList

## Goal
`MonthGrid` looks and behaves like `PATTERN: MonthGrid` (`PLAN/kit/patterns.html`, `grep -n "PATTERN: MonthGrid"`):
the shared `MonthHeader` (`অক্টোবর ২০২৬`, আজ, prev/next), today ringed, a selected day, chips on
desktop and dots on phone. `DayPanel` lists the selected day's events (with an optional per-event
badge, e.g. a "খসড়া" draft StatusBadge). Every existing caller keeps compiling: the new MonthGrid props
are optional. Split note: routine grid/agenda and the attendance month grid moved to **31.2.3b**
(same lane, runs after this ticket).

## Steps
1. **`MonthGridEvent`** (`month-grid.tsx`) — add `badge?: React.ReactNode` (doc: "rendered after the
   name in `DayPanel` only — e.g. `<StatusBadge tone="neutral" label={t('draft')} />` for an unpublished
   event; shared request calendar"). MonthGrid chips ignore it (no room in a cell).
2. **MonthGrid props** (`month-grid.tsx:24-38`) — add, all optional so no route changes in wave 2:
   ```ts
   selectedDate?: string;                      // "2026-10-08"; default = today
   today?: string;                             // default toIsoDate(new Date())
   onMonthChange?: (month: string) => void;    // when set, MonthGrid renders its own MonthHeader
   ```
   (patterns.md §8 lists them as required; optional here = backward compatible — wave-4 calendar
   pages pass them.) Read `config = useRegionConfig()` and `t` (`useTranslation('common')`) inside.
3. **MonthGrid markup.**
   - Wrapper: `rounded-lg border border-border-subtle bg-surface shadow-e1 overflow-hidden`, keep
     `data-testid="month-grid"` and `role="grid"`; `aria-label={formatMonth(month, config)}` (was the raw
     `month`, `:152`).
   - Header (only when `onMonthChange`): `<div className="p-3 md:px-4"><MonthHeader label={formatMonth(month, config)} onPrevious={() => onMonthChange(prev)} onNext={…} onToday={() => { onMonthChange(today.slice(0, 7)); onDayClick?.(today); }} /></div>`;
     prev/next month strings computed with `Date.UTC` like `buildDays` (`:53-73`). Term bands
     (`data-testid="term-bands"`, keep) move under the header: chips `rounded-sm bg-muted px-2 py-0.5 text-caption text-text-secondary`.
   - Weekday band: `grid grid-cols-7 border-t border-border-subtle bg-muted text-center text-label text-text-secondary`, cells `h-8 flex items-center justify-center`; keep `data-weekly-off`.
   - Grid: `grid grid-cols-7 gap-px border-t border-border-subtle bg-border-subtle` (the gaps are the lines).
   - Cell: stays a `<div role="gridcell" tabIndex>` — it hosts chip buttons, and a button cannot nest
     a button (keep the comment `:183-188`). Classes:
     `flex min-h-12 min-w-0 flex-col items-center gap-1 p-1 text-start md:min-h-24 md:items-stretch md:p-1.5`
     + ground: selected `bg-secondary`, else weekly off `bg-muted`, else outside month `bg-bg`, else `bg-surface`.
     Keep `data-testid={\`day-cell-${day}\`}`, click/keyboard handling (`:113-146`, `:197-202`).
   - Day number: `<span className="flex size-7 items-center justify-center rounded-full text-label">`
     with `renderDigits(String(Number(day.slice(8, 10))), config.numerals)`; today
     `font-semibold text-primary ring-2 ring-primary ring-inset`; selected `bg-primary font-semibold text-primary-foreground`;
     outside month `text-text-secondary opacity-60`. Same states as the DatePicker day.
   - ARIA: `aria-current="date"` on **today's** cell (today it sits on the focused cell, `:195` — the
     U3 bug); `aria-selected` on the selected cell; `aria-label` = `formatDate(day, config)` plus
     ` (${term.name})` when a term covers it (was the ISO string, `:196`). Initial roving focus = the
     selected day if it is in the grid, else today, else `days[0]` (`:103`).
   - Events — desktop: `<div className="mt-1 hidden min-w-0 flex-col gap-0.5 md:flex">` with the chip
     buttons (keep `stopPropagation` + `onEventClick`, `:212-225`); chip =
     `<EventTypeBadge type label={event.name} className="w-full truncate rounded-sm px-1.5 py-0.5 text-caption" />`;
     keep `maxEventsPerCell` + `moreLabel` overflow (`text-caption text-text-secondary`, replaces `text-[11px]`).
     Phone: `<div aria-hidden="true" className="flex gap-0.5 md:hidden">` with up to 3
     `<span className={cn('size-1.5 rounded-full', EVENT_DOT_CLASSES[event.type])} />`.
     Both render in jsdom, so `within(cell).getByText(name)` keeps working.
4. **`event-type-badge.tsx`** — switch the `[…].join(' ')` to `cn()` so a caller's `rounded-sm` /
   `text-caption` override wins, and set the kit tones (patterns.md §8):
   `EXAM → bg-status-partial-bg text-status-partial-fg`, `HOLIDAY → bg-status-overdue-bg text-status-overdue-fg`,
   `DEADLINE → bg-status-due-bg text-status-due-fg`, `EVENT` and `MEETING → bg-secondary text-secondary-foreground`.
   Export `EVENT_DOT_CLASSES: Record<CalendarEventType, string>` from this file (not from `index.ts`):
   `EXAM bg-status-partial-fg`, `HOLIDAY bg-status-overdue-fg`, `DEADLINE bg-status-due-fg`, others `bg-primary`.
5. **DayPanel** (props final from 31.1.2a; shared request portal_calendar — the empty-day sentence — is `dayPanel.empty`, already in 31.1.2a's key table): `<aside aria-labelledby={id} className="rounded-lg border border-border-subtle bg-surface p-4 shadow-e1 md:w-80 md:shrink-0 md:p-5">`
   → `<h3 id={id} className="text-h3">{formatDate(date, config)}</h3>` → `<p className="text-text-secondary">{formatWeekday(date, config)} · {t('dayPanel.eventCount', { count: events.length })}</p>`
   → no events: `<p className="mt-3 text-text-secondary">{t('dayPanel.empty')}</p>`; else
   `<ul className="mt-2 divide-y divide-border-subtle">`, row `flex items-start gap-3 py-3`:
   dot `mt-2 size-2 shrink-0 rounded-full` + `EVENT_DOT_CLASSES[type]`, then name (`font-medium`; a
   `<button type="button">` with `text-start hover:underline` when `onEventClick`), then detail
   `text-text-secondary` = `event.startDate === event.endDate ? event.typeLabel : \`${formatDateRange(event.startDate, event.endDate, config)} · ${event.typeLabel}\``.
   (The kit's time/place detail needs fields `MonthGridEvent` does not have — D1, not added.) Placing
   the panel beside / under the grid (`flex flex-col gap-4 md:flex-row md:items-start md:gap-6`) is the
   calendar page's job (wave 4).
6. **AgendaList** — `formatDayHeading?` becomes optional, default `(day) => formatDate(day, config)`
   (`useRegionConfig()`); heading `text-h3`; each row = the DayPanel row look (dot + name +
   `typeLabel` in `text-text-secondary`) instead of the badge + name (`:75-82`). Keep `data-testid`s.
