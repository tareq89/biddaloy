# [31.3.8a] wave 3 — drop the legacy AppShell props; make shared e2e specs survive the page redesigns

## Goal
`AppShell` loses the two props wave 2 deprecated (`mobileHeaderActions`, `drawerHeader`) now that no layout passes them, and the shared e2e files that several wave-4 page tickets would otherwise break are made independent of the exact page wording, page size, dialog role and tab counts — so wave-4 PRs stay green without editing shared specs.

## Files
- `ui/src/components/app-shell.tsx` (changed) — remove `mobileHeaderActions`, `drawerHeader` and the legacy phone row.
- `ui/src/components/app-shell.test.tsx` (changed) — delete the legacy cases.
- `ui/src/components/app-shell.stories.tsx` (changed) — drop any story arg using them.
- `e2e/config.ts` (changed) — `shells.app.heading` read from the locale file, not a literal.
- `e2e/reduced-motion.spec.ts` (changed) — sign-in button by key, not literal.
- `e2e/a11y/overlay-openers.ts` (changed) — `expectDialogOpen` accepts `dialog` or `alertdialog`.
- `e2e/keyboard/organisation-structure.spec.ts` (changed) — Tab budgets that survive new header/row controls.
