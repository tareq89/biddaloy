## Steps
1. **`--color-destructive-foreground` (D31, C18).** In `globals.css`, inside `@theme`, directly
   after `--color-destructive: var(--color-status-overdue-fg);` (`:376`) add
   `--color-destructive-foreground: var(--color-neutral-0);`. In `:root[data-theme="dark"]`,
   directly after `--color-primary-foreground: var(--color-neutral-900);` (`:728`) add
   `--color-destructive-foreground: var(--color-neutral-900);`. Comment on each: contrast is
   already gated — WCAG ratio is symmetric, so white-on-`#b91c1c` is the existing CONTRAST_PAIRS
   row `'overdue fg on white'` (`ui/tailwind.preset.ts:274`, 6.47:1) and neutral-900-on-`#f87171`
   is `'overdue fgDark on dark bg'` (`:283`, dark `--color-bg` is neutral-900). Do **not** add new
   rows: the preset's own rule (`tailwind.preset.ts:303-308`) is "only genuinely new numeric pairs
   get their own entry". This makes `text-destructive-foreground` (already used by
   `notification-bell.tsx:102`) a real class.
2. **Phone density (C2).** Directly after the `[data-density='comfortable'] { … }` block
   (`:643-646`) add:
   ```css

      Same two variables, so every `h-[var(--control-h,…)]` utility lifts with no prop. */

     :root {
       --control-h: 2.75rem;
       --target-inset: 0.875rem;
     }
   }
   ```
   Edit the density comment above (`:588-641`): the line "There is deliberately NO
   `:root { --control-h: ... }` default" gets a follow-up sentence: "The one exception is the
   phone media rule below: under `md` the variable is set on `:root` for every shell (C2)."
   and "compact — staff routes … The DEFAULT" becomes "compact — staff routes at `md` and up".
3. **Pointer cursor (D18, C24).** Inside the existing `@layer base { … }` (`:674`), after the
   `scroll-margin-top` rule, add:
   ```css
   button:not(:disabled),
   [role='button']:not([aria-disabled='true']),
   [role='tab'],
   [role='menuitem'],
   [role='menuitemradio'],
   [role='menuitemcheckbox'],
   [role='option'],
   a[href],
   summary,
   ```

   existing `extendTailwindMerge` call (`:39-45`):

   ```ts
     extend: {

       classGroups: { shadow: [{ shadow: ['e1', 'e2', 'e3'] }] },
   ```

   and add one paragraph to the file's doc comment ("second deviation: the type ramp of
   09 §2 is a font-size, not a colour"), same style as the elevation note. Every kit class string
   (`text-label text-text-secondary`, `text-caption text-destructive`, …) depends on this.
5. **Control radius (C10).** `primitives/input.tsx:16` and `primitives/textarea.tsx:14`:
