# [31.2.14c] ui — upload & approval components: translated FileUpload, host-owned Confirm in BulkUploadPreview, step-up scope labels, kit SecretField

## Goal
`FileUpload` speaks the user's language (no hard-coded English); `BulkUploadPreview` can hand its state and
Confirm to a `FullPageShell` footer so an import page has exactly one primary (CONTRACT Addendum 7);
`AdminVerificationModal` names the `fees.discount` / `payments.reverse` scopes once their labels exist (D9);
`SecretField` has kit sizes and an optional described help line. Existing callers render as before
unless they opt in.

     render: `{ status: state.status, result: 'result' in state ? state.result : undefined, commitResult: state.status === 'done' ? state.commitResult : undefined, confirmDisabled, confirm, reset: handleReset }`.
   - Report it: `React.useEffect(() => { onControllerChange?.(controller); }, [state.status, result, commitResult, confirmDisabled])`
     — hold `onControllerChange`, `confirm` and `handleReset` in refs (`useLatest` pattern: `ref.current = fn` during render)
     so the effect does not re-fire on every render and the host's `setState` cannot loop. Document: "the host
     stores it in state and renders its footer from it; `confirm`/`reset` are stable".
   - `hideConfirm` true: do not render the in-card Confirm button nor the `Card` frame of the preview (the host
     card already frames it — no nested cards, patterns §10); render instead the file row from the mockup:
     `div.flex.flex-wrap.items-center.gap-3.rounded-md.border.border-border-subtle.p-3.md:flex-nowrap` → icon well
     `flex size-10 shrink-0 items-center justify-center rounded-md bg-muted text-text-secondary` (`FileSpreadsheetIcon`)
     → `min-w-0 flex-1` with `truncate font-medium` file name (`selectedFile?.name`) and `text-caption text-text-secondary`
     status (`t('validating')` / `t('done')` / nothing) → ghost `Button` `w-full md:w-auto` with `RotateCcwIcon` +
     `t('uploadAnother')` calling `handleReset`. The `confirmSlot` still renders (its hold still feeds `confirmDisabled`).
   - Both modes, kit look: preview `Card` (when shown) `padded` instead of `p-4`; expiry line

   - Default (no `hideConfirm`) keeps today's buttons, so `settings` restore and every current caller are unchanged.
