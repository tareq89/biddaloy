# [31.2.4b] ui — DataTable: total count in the footer, page size 25, no pager when empty, kit look

## Goal
Every `DataTable` shows its total (`Showing 1–25 of 312` or `Total 12`), defaults to 25 rows per page with options 25/50/100, hides the pager on an empty table, can show a real `EmptyState`, and looks like the kit table (header band, 40 px rows, framed card).

- `ui/src/components/data-table-cards.tsx` (changed) — card classes, `EmptyState` slot
- `ui/src/components/pagination.tsx` (changed) — same count + icon pager as DataTable

3. **`data-table.tsx` props**:
