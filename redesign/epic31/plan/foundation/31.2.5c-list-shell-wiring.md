# [31.2.5c] ui — ListShell: filter sheet shows the result count, empty state reaches the table

## Goal
On every `ListShell` page the phone filter sheet's primary button reads "৪৮টি ফলাফল দেখুন"
(the list's `totalCount`) with no page change, and a page can hand `ListShell` a DataTable
`emptyState` and get the kit EmptyState instead of the plain "No results" cell (CONTRACT Addendum 7).

## Steps
1. **Read first**: `ui/src/shells/list-shell.tsx` as left by 31.2.5a; `FilterBarProps.resultCount`
   (added by 31.2.7a); `DataTableProps.emptyState` / `paginated` (added by 31.2.4b).
2. **`resultCount`** (owner of request (d) in the I-1 brief): where the shell renders the typed filter
   bar (`{filters && <FilterBar {...filters} />}`, `list-shell.tsx:79` today), pass
   `<FilterBar {...filters} resultCount={filters.resultCount ?? dataTableProps.totalCount} />` — a page
   that sets its own `resultCount` still wins. Do not pass it while `dataTableProps.loading` is true
   (`resultCount={dataTableProps.loading ? undefined : …}`), so the sheet says "ফলাফল দেখুন" instead of
   a stale number during a refetch.

   `DataTable`, so `emptyState` and `paginated` already pass through. Add one sentence to the file's

   (31.2.4b) reach DataTable through the same spread."
