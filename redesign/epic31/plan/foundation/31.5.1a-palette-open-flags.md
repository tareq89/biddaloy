# [31.5.1a] client-admin — palette landing flags: open create dialogs from the URL

## Goal
Every create/record dialog that 31.5.1b registers in the `Ctrl+K` palette opens when its list page is reached with a one-shot search flag (`?new=1`, …), and the flag is cleared when the dialog closes — the landing contract the palette's `run()` (which can only `navigate({ to })`) depends on.

- `client-admin/src/routes/_staff/calendar/index.tsx` (changed) — `?panel=clone` opens `CloneDialog` (the event form and holidays already open from `?panel=new-event` / `?panel=holidays`, calendar-1a/1b)

4. **Schema.** Calendar: add `'clone'` to the existing `panel` enum and open/close `CloneDialog` from it exactly like calendar-1a does for `holidays` (`open={search.panel === 'clone'}`, closing clears `panel` with `replace: true`). Pages that already have `validateSearch` (`fee-structures`, `guardians`, `staff`, `students`): add the key to the existing `z.object`, same line shape as `create` in `exams/index.tsx:35`. Pages with no `validateSearch` today (`academic-years`, `classes`, `grading-scales`, `exams/templates`): add `validateSearch: z.looseObject({ new: z.coerce.string().optional().catch(undefined) })`. It must be `z.looseObject` (zod 4), not `z.object`: a plain object schema strips every key it does not list, which would wipe the list-state params `ui/src/routes/use-list-url-state.ts` reads with `useSearch({ strict: false })` (`page`, `limit`, `sort`, filters).
5. **Open + clear.** For each row: initialise the existing state from the flag AND the gate (`useState(canX && search.new === '1')`), add the `useEffect` from `exams/index.tsx:74-78` (also checking the gate), and in the dialog's close path clear only that flag (`replace: true`). Keep the existing button's `setXOpen(true)` as it is.
6. **`TemplatesList`** (`exams/-templates-list.tsx:28-38`): add two optional props, `openCreate?: boolean` and `onCreateClosed?: () => void`. Initialise `createOpen` from `openCreate`, re-open in an effect when it turns true, and call `onCreateClosed` when the dialog closes. `exams/templates/index.tsx` passes `openCreate={search.new === '1'}` and an `onCreateClosed` that clears `new`. Existing props and the Exams-page usage stay unchanged.
7. **One test file** `client-admin/src/routes/_staff/palette-flags.test.tsx`, cloned from the third case of `client-admin/src/routes/_staff/exams/index.test.tsx` ("opens the create dialog when ?create=1 …"): `it.each` over `{ url, role, dialogName }` rows (10 rows), each `renderWithRouter(routeTree, { initialEntries: [url], tenantId: 'tenant-1', role, locale: 'en' })`, `await screen.findByRole('dialog', { name })`, press Escape, assert the dialog is gone and the flag left the URL (`router.state.location.search`). Add the MSW handlers each page needs (copy them from that page's own `index.test.tsx`). Add one negative row: a role without the gate (e.g. `TEACHER` on `/guardians?invite=1`) renders no dialog.
