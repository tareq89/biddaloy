## Goal
The guardian/student portal uses the same `AppShell` behaviour as staff (D33): one 56 px phone row with menu + school name and search · bell · account, language and theme in the account menu, exactly one active sidebar item and one marked bottom cell, distinct icons, and a sidebar item for `/portal/surveys` — matching `starter-portal.html`.
