# [31.2.10] ui — bottom bar fixed with a page reserve, kit cells, bell badge up to 9999

## Goal
On phones the bottom bar is `fixed` to the viewport bottom, the shell reserves exactly its height (no content hidden behind it, no stray gap on short pages), its cells match the kit with a marked current cell and a markable "More", and the bell badge is a 4-digit pill with a real foreground token.

## Steps

2. **`app-shell.tsx` — fixed bar and reserve (D14, B4, C1).** Today the bar wrapper is `sticky bottom-0 z-10` in normal flow (`:534`), the root is `min-h-screen` (`:454`) and `<main>` adds `pb-[calc(6rem+var(--safe-area-bottom))]` (`:528`) — so every phone page scrolls past an extra 64 px bar + 96 px pad even when it is short.
   - Bar wrapper: `{hasBottomNav && <div data-app-bottom-nav className="fixed inset-x-0 bottom-0 z-30 md:hidden">{bottomNav}</div>}`.
   - Root: `cn('flex min-h-dvh flex-col', hasBottomNav && 'pb-[calc(4rem+var(--safe-area-bottom))] md:pb-0')`. 4 rem = the `h-16` cell (step 3); `--safe-area-bottom` is the bar's own bottom padding (`ui/src/styles/globals.css:583`). Border-box `min-h-dvh` includes that padding, so a short page ends exactly at the bar's top edge.
   - `<main>`: drop the `hasBottomNav &&` padding line, and make the page gutter D15/D17's 16 / 24 px: `<main>` is `min-w-0 flex-1 p-4 md:p-6` in every case (today `p-6`). The gutter stays on `<main>` rather than in `PageContainer` because 54 of 103 leaf routes render no shell yet — 31.2.5a's `PageContainer` deliberately carries width only and asks this ticket for the `p-4 md:p-6` change.
   - No toast hand-off needed: 31.2.8b lifts the toaster itself below `md` (`calc(5rem + var(--safe-area-bottom))` = this bar's 4 rem + 1 rem gap). Keep the bar at `h-16` so that number stays right.

3. **`bottom-nav.tsx` — kit cells (D14, C §D).**

   - Drop `activeProps` / `inactiveProps` (`:129-130`): the `aria-current="page"` TanStack sets drives the look through the `aria-[current=page]:` variants. Keep the `hasDescendantItem` + `exact` rule (`:81-84,122`) unchanged.

Render `data-active={more.active ? 'true' : undefined}` on the More `<button>`; never `aria-current` (it opens the drawer, not a page).
   - Update the header comment (`:27-31`): cells are `h-16` (64 px).
