# [31.4.fees-3a] Create fee bills — readable rounds, one primary, no toast

## Goal
`/fees/generate` matches the "after" screenshots of `fees_generate` (header with subtitle and one filled "বিল তৈরি করুন", labelled filters, month names instead of ISO dates, translated status badges, a "how created" column that also covers fine-rule rounds, a "view bills" icon action, a visible total, 25 rows per page), the create flow opens through `?generate=1`, and the red "no permission" toast is gone (B9).

Split: this is part **a** (the list page). Part **b** (`ticket-b.md`, fees-3b) turns the create form into a full-page modal and runs after this one.

## What and why
This page is the log of every billing round (a set of fee bills created together) and the place to start a new one. Today the period reads `২০২৬-০১-০১ · মাস` as an underlined link, statuses say "None/Partial/Full" in English, rounds created by a fine rule show a blank "source" (and the filter calls them "Schedule"), the date filter shows `YYYY-MM-DD`, the pager never says how many rounds exist, and an accountant gets a red "no permission" toast on open because the "generated by" filter loads the staff list. The redesign builds the page from the kit: PageHeader, FilterBar with labels, DataTable with StatusBadge, RowActions and TableCount, and only loads the staff list for people allowed to read it.
