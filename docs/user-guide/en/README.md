# Welcome to SchoolManager 👋

Less paperwork. More time for your school.

SchoolManager is designed to help school teams organize everyday work and keep
school families connected. This guide will grow into a simple handbook for
administrators, accountants, teachers, students, and guardians.

## Choose your language

Use the language picker at the top of the documentation site to switch to
বাংলা. The Bangla and English guides are separate versions of the same handbook.

## What you will find here

- Friendly introductions for each role
- Step-by-step instructions for common tasks
- Examples that explain what to expect after an action
- Help for common questions and problems

The full handbook is still being written, so some sections only have an
introduction for now. New pages appear as they are finished.
