# Printing and ID cards

SchoolManager can print **ID cards** for students and staff. You design a card
once, then print it for one person, a few people, or a whole class. Every card
you print is remembered, so you can reprint it later or cancel a lost card.

## Who can do what

| Role       | What they can do                                              |
| ---------- | ------------------------------------------------------------- |
| Admin      | Everything: design cards, add printers, print, see history, cancel a card |
| Accountant | Print and reprint cards                                       |
| Executive  | See the print history                                         |

Printing a **staff** card also needs permission to see staff HR records.

## Your first ID card in 5 minutes

1. Go to **Settings → Printers** and add the printer you will use
   ([why this matters](printers-and-calibration.md#why-do-i-choose-the-printer-myself)).
2. Go to **Administration → Print templates** and press **New template**.
   Pick a ready-made design ([more](templates.md#create-a-template-from-a-ready-made-design)).
3. Press **Publish**. Make it the **default** if asked.
4. Open a student, choose the **Documents** tab and press **Print ID card**
   ([more](printing-id-cards.md#print-one-card)).
5. In the preview, check the card, choose your printer, press **Print**.
6. When the cards come out, answer **"Did all print correctly?"**
