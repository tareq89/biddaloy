# Templates: designing a card

A **template** is the design of a card: the background picture, and where the
name, photo, class and QR code go. You make a template once and use it for every
card.

**Who can do this:** Admin.

## Create a template from a ready-made design

1. Open **Administration → Print templates**.
2. Press **New template**.
3. Choose a design. Cards come in **portrait** or **landscape**, in a
   **classic** or **modern** style, for **students** or **staff**.
4. Give it a name, for example "Student ID 2027", and press **Create**.

The editor opens with the design ready. You can print it as it is, or change it.

## A tour of the editor

The editor takes the whole screen. It works on a computer, not on a phone.

- **Middle:** the card. Click a piece to select it, drag to move it.
- **Left, Layers:** every piece on the card, in order. The top one is in front.
- **Right, Properties:** size, position, font, colour and alignment of the
  selected piece.
- **Top:** the template name, save status, undo and redo, zoom, front/back, **Publish**, and **Back to templates**.
- **Tabs on the left:** **Layers**, **Page** (paper size and sides) and **Files**
  (artwork, images and fonts).

Your work is saved by itself a moment after you stop typing. The top bar says
**Saved** when it is safe.

### Move things with the keyboard

| Keys                        | What happens                      |
| --------------------------- | --------------------------------- |
| Arrow keys                  | Move the selected piece by 0.5 mm |
| Shift + arrow keys          | Move by 5 mm                      |
| Delete                      | Remove the selected piece         |
| Ctrl + Z / Ctrl + Shift + Z | Undo / redo                       |
| `[` and `]`                 | Send backward / bring forward     |
| Esc                         | Deselect                          |

## Fields

A **field** is a piece that changes for each person: name, class, roll, photo,
blood group, the QR code and so on. Choose a field in Properties. The card shows
sample text so you can see how it looks.

## When a name is too long

For every text field, choose what happens when a long name does not fit:

- **Shrink** — the text gets smaller until it fits. (Best for names.)
- **Wrap** — the text goes on to a second line.
- **Clip** — the extra text is cut off.
- **Flag** — the card is marked "needs attention" in the preview, so you can
  fix it before printing.

Turn on **Longest values** in the **Sample** bar to test with the longest
realistic names. If your design still looks good, it is safe.

## Publish, versions and the default template

- Press **Publish v1** (the number counts up) when the design is ready, then
  confirm. This makes a numbered **version**. Versions never change.
- If you edit again and publish again, the next number is used. Cards printed
  earlier keep the version they were printed with, so history stays true.
- The **default** template is the one used when you press **Print ID card**.
  There is one default for students and one for staff. Make a template the
  default from the library.

## If something goes wrong

- **Publish is greyed out.** Wait for **Saved**, or fix the problem shown next
  to the button.
- **A piece jumps to the edge.** Pieces are kept inside the card. Make the card
  bigger in the **Page** tab, or make the piece smaller.
- **I made a mistake.** Press undo. You can undo the last 50 steps.
