# Glossary

The words this guide uses most, each with a plain meaning and an example. If a
word is new to you, look it up here. Spellings match what you see on screen.

- [School words](#school)
- [The three states: where your work has reached](#states)

## School words <a href="#school" id="school"></a>

| Word                                                                                   | Meaning                                                                                                       | Example                                                  |
| -------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------- |
| <a id="section"></a>**Section**                                                        | A part of a class. Students of one class sit in separate sections.                                            | Class 6, section B.                                      |
| <a id="class"></a>**Class**                                                            | The level a student studies at.                                                                               | Class 6.                                                 |
| <a id="shift"></a>**Shift**                                                            | The part of the day a class runs in, such as morning or day.                                                  | Class 6 sections A and B in the morning shift.           |
| <a id="version"></a>**Version**                                                        | The medium a class is taught in, such as Bangla or English.                                                   | Class 6, Bangla version.                                 |
| <a id="group"></a>**Group**                                                            | The stream of subjects in higher classes, such as science, commerce or humanities.                            | Class 9, science group.                                  |
| <a id="academic-year"></a>**Academic year**                                            | One school year of study. Admissions, fees and results run by this year.                                      | The 2026 academic year.                                  |
| <a id="roll-number"></a>**Roll number**                                                | A student's serial number in a section. The attendance register lists names in this order.                    | Roll 12.                                                 |
| <a id="role"></a>**Role**                                                              | Your job in the school's system. It decides what you can see and do.                                          | Teacher, accountant, admin.                              |
| <a id="dashboard"></a>**Dashboard**                                                    | The first page after you sign in. Your most urgent work shows here as cards.                                  | The **Attendance pending** card.                         |
| <a id="fee-structure"></a>**Fee structure**                                            | The list of what students of a class pay, for which fee, and how much.                                        | Class 6 monthly tuition.                                 |
| <a id="dues"></a>**Dues**                                                              | The money a student has not yet paid.                                                                         | January tuition still unpaid.                            |
| <a id="invoice"></a>**Fee bill**                                                       | The fee bill made for one student. It says how much, for which fee, and by when.                              | The fee bill for January tuition.                        |
| <a id="payment"></a>**Payment**                                                        | The record of money the school received.                                                                      | 500 taka received in cash.                               |
| <a id="receipt"></a>**Receipt**                                                        | The proof you get after money is received.                                                                    | A tuition receipt.                                       |
| <a id="fine"></a>**Fine**                                                              | Money charged for breaking a rule, such as an unexplained absence.                                            | 20 taka under a fine rule.                               |
| <a id="guardian"></a>**Guardian**                                                      | A student's parent or carer. The school contacts them.                                                        | The student's mother.                                    |
| <a id="attendance-register"></a>[**Attendance register**](../attendance/attendance.md) | One section's attendance for one day. Every section has one per day.                                          | Class 6 section B's register for today.                  |
| <a id="monthly-register"></a>**Attendance register (monthly)**                         | The page that shows a whole month of attendance together.                                                     | The register for January.                                |
| <a id="draft"></a>**Draft**                                                            | Something that is in the system but is not yet counted as final.                                              | A section showing **Draft** after you submit.            |
| <a id="leave"></a>**Leave**                                                            | The status when a student or staff member is away and has told the school.                                    | Leave told in advance.                                   |
| <a id="report"></a>**Report**                                                          | A page that gathers the system's data in one view.                                                            | The attendance report.                                   |
| <a id="teacher-assignment"></a>**Teacher assignment**                                  | The list of which teacher teaches which section and subject. Without it, a teacher does not see that section. | Mr Rahim: Class 6 section B, maths.                      |
| <a id="calendar"></a>**Calendar**                                                      | The school's holidays, exams and event dates.                                                                 | Friday is the weekly off day.                            |
| <a id="palette"></a>Search box (Ctrl+K)                                                | The place where you type a page name to find it. Press Ctrl and K together to open it.                        | Typing "attendance" to open the page.                    |
| <a id="offline"></a>**Offline**                                                        | Without an internet connection.                                                                               | No signal out in the playground.                         |
| <a id="sync"></a>**Sync**                                                              | Sending work kept on the device to the school's system once the internet is back.                             | **Saved on device — will sync when you're back online**. |
| <a id="sign-in"></a>**Sign in**                                                        | Entering the system with your name and password.                                                              | Signing in with a phone number and password.             |

## The three states: where your work has reached <a href="#states" id="states"></a>

On every page where something is saved, these three names always mean the same thing.

| State                           | Meaning                                                                                               |
| ------------------------------- | ----------------------------------------------------------------------------------------------------- |
| **Changed on screen only**      | The mark is beside the name, but you have not submitted yet. Nothing has reached the system.          |
| **Saved on this device**        | The work is kept on your phone or computer. It goes to the school's system when the internet is back. |
| **Reached the school's system** | The work is submitted to the school's system. You or anyone else will see it on any device.           |

## Record names <a href="#nouns" id="nouns"></a>

Each page calls its main record by one name and keeps it for the whole page.

| Part       | Name                            |
| ---------- | ------------------------------- |
| Attendance | **attendance register**         |
| Attendance | **monthly attendance register** |
| Fees       | **fee bill**                    |
| Fees       | **tuition receipt**             |
| Fees       | **student dues**                |

When a new page is written, its record name is added here.
