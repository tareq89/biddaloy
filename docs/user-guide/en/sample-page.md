# A sample Biddaloy task

> **Sample content:** This page is a template example. It does not describe a
> live feature yet.

## What this page will explain

When a real tutorial is added, it will start by explaining what the task does,
who can do it, and when it is useful.

## Before you start

1. Make sure you have the role and access needed for the task.
2. Make sure the school information used in the example is ready.

## Steps

1. Open the relevant area of Biddaloy.
2. Choose the action described by the tutorial.
3. Enter the requested information.
4. Save the change and check the confirmation message.

## Check the result

You should see the new information in the relevant list or detail page. A
future version of this page will include real labels, screenshots, and a short
walkthrough after the workflow has been verified in the application.

## If something goes wrong

If you cannot see an action, ask your school administrator to check your access.
Do not treat this sample page as a troubleshooting guide for a live task.
