# SchoolManager-এ স্বাগতম 👋

কম কাগজপত্র। স্কুলের জন্য আরও বেশি সময়।

SchoolManager স্কুলের প্রতিদিনের কাজ গুছিয়ে রাখতে এবং স্কুল ও পরিবারের মধ্যে
যোগাযোগ সহজ করতে সাহায্য করার জন্য তৈরি। এই গাইডটি প্রশাসক, হিসাবরক্ষক,
শিক্ষক, শিক্ষার্থী এবং অভিভাবকদের জন্য একটি সহজ সহায়িকা হিসেবে ধীরে ধীরে
বড় হবে।

## ভাষা বেছে নিন

ডকুমেন্টেশন সাইটের উপরের ভাষা বাছাই মেনু থেকে **English** নির্বাচন করে ইংরেজি
গাইডে যেতে পারবেন। বাংলা ও ইংরেজি গাইড একই হ্যান্ডবুকের আলাদা সংস্করণ।

## এখানে যা পাবেন

- প্রতিটি ভূমিকার জন্য সহজ পরিচিতি
- সাধারণ কাজের ধাপে ধাপে নির্দেশনা
- কোনো কাজ করার পর কী আশা করবেন তার উদাহরণ
- সাধারণ প্রশ্ন ও সমস্যার সমাধান

পূর্ণ সহায়িকা এখনো লেখা হচ্ছে, তাই কিছু অংশে আপাতত শুধু পরিচিতি আছে। পাতা
শেষ হওয়ার সাথে সাথে নতুন পাতা যোগ হবে।
