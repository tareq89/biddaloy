# প্রিন্টার ও ক্যালিব্রেশন

**কে করতে পারেন:** প্রিন্টার যোগ করতে পারেন অ্যাডমিন। যিনি ছাপেন, তিনি প্রিন্টার বেছে নেন।

## কেন প্রিন্টার আমাকে নিজে বেছে নিতে হয়?

প্রিন্ট চাপলে আপনার ব্রাউজার নিজের প্রিন্ট উইন্ডো খোলে, সেখানে আপনি প্রিন্টার বাছেন।
**আপনি সেখানে কোন প্রিন্টার বাছলেন, SchoolManager তা দেখতে পায় না।** এটি ব্রাউজারের নিয়ম, আর
এতে আপনার গোপনীয়তা রক্ষা পায়।

কিন্তু প্রতিটি প্রিন্টার একটু আলাদাভাবে ছাপে: একটি ছবি ১ মিমি ডানে সরিয়ে ছাপে, আরেকটি বেশি
ধার ছেড়ে দেয়। SchoolManager এটা ঠিক করে দিতে পারে, তবে প্রিন্টারটি চিনলে তবেই। তাই ছাপার
**আগে** SchoolManager-এও একই প্রিন্টার বেছে নিন। তখন সে ওই প্রিন্টারের ধার ও সংশোধন পাতায়
লাগিয়ে দেয়।

সহজ নিয়ম: **SchoolManager-এ আর প্রিন্ট উইন্ডোতে একই প্রিন্টার বাছুন।** এই কম্পিউটারে আপনার
শেষবারের পছন্দ মনে রাখা হয়।

## প্রিন্টার যোগ করুন

1. **সেটিংস → প্রিন্টার** খুলে **প্রিন্টার যোগ করুন** চাপুন।
2. এমন নাম দিন যা সবাই চিনবে, যেমন "অফিসের কার্ড প্রিন্টার"।
3. **ধরন** বাছুন:
   - **কার্ড প্রিন্টার** — একবারে একটি কার্ড, কিনারা পর্যন্ত ছাপে।
   - **অফিস প্রিন্টার** — A4 কাগজে কার্ড ছাপে, পরে কেটে নিতে হয়। এতে ধার ছাড়া থাকে (শুরুতে
     ৫ মিমি ঠিক আছে) আর কার্ডের মাঝে অল্প ফাঁক থাকে।
4. **দুই পাশ** কীভাবে ছাপা হবে বাছুন: **দুই পাশ নিজে থেকে ছাপে**, অথবা **আমি নিজে হাতে
   কাগজ উল্টে দিই**।
5. আপাতত অফসেট ০ আর স্কেল ১ রেখে **সংরক্ষণ** করুন।

## আগে ছাপা কার্ডের কাগজ (প্রি-প্রিন্টেড)

স্কুল যদি এমন খালি কার্ড কেনে যাতে নকশা আগেই ছাপা আছে, তাহলে শুধু নাম, ছবি আর কিউআর কোড
ছাপাতে হবে। এডিটরে **ফাইল** খুলে "ব্যাকগ্রাউন্ড ছাপুন" **বন্ধ** করুন। ছবি পর্দায় দেখা যাবে, কিন্তু
ছাপা হবে না।

## প্রিন্টার ক্যালিব্রেট করুন (ধাপে ধাপে)

প্রতিটি প্রিন্টারে একবার করুন। কাগজ বা কার্ডের ধরন বদলালে আবার করুন।

1. **সেটিংস → প্রিন্টার**-এ প্রিন্টারের পাশে **ক্যালিব্রেশন পাতা ছাপুন** চাপুন।
2. প্রিন্ট উইন্ডোতে **Margins: None** আর **Scale: 100%** দিন। ("Fit to page" থাকলে বন্ধ করুন।)
   একই প্রিন্টার বাছুন। ছাপুন।
3. একটি স্কেল নিন। **কাগজের ওপরের বাঁ কোণ** থেকে প্রথম **ক্রস** পর্যন্ত মাপুন। এটি **ঠিক
   ২০ মিমি** হওয়ার কথা।
4. পার্থক্য লিখে রাখুন। ক্রস ১ মিমি বেশি **ডানে** থাকলে অফসেট **X = −১**। ০.৫ মিমি বেশি
   **নিচে** থাকলে **Y = −০.৫**।
5. **অফসেট বদলান** চেপে সংখ্যা লিখে সংরক্ষণ করুন।
6. পাতাটি আবার ছাপুন। ক্রস এখন ২০ মিমিতে থাকার কথা। না থাকলে আবার করুন।

## প্রিন্ট উইন্ডোর সেটিংস

কার্ড ছাপার সময় প্রতিবার ব্রাউজারের প্রিন্ট উইন্ডোতে এগুলো দিন:

| সেটিং               | মান                                 |
| ------------------- | ----------------------------------- |
| Printer             | SchoolManager-এ যেটি বেছেছেন, সেটিই |
| Margins             | **None**                            |
| Scale               | **100%** ("fit to page" নয়)        |
| Headers and footers | বন্ধ                                |
| Background graphics | চালু                                |

## কিছু ঠিক না হলে

- **ছাপা সরে গেছে।** আবার ক্যালিব্রেট করুন (ওপরে দেখুন)।
- **কার্ডে সাদা ধার।** অফিস প্রিন্টার কিনারা পর্যন্ত ছাপতে পারে না। কার্ড প্রিন্টার ব্যবহার করুন,
  বা নকশায় ব্লিড দিন ([ডিজাইনারের গাইড](designer-guide.md#৩-নিরাপদ-এলাকা-ও-ব্লিড))।
- **প্রিন্ট চাপলে কিছু খুলছে না।** ব্রাউজার পপ-আপ আটকে দিয়েছে। SchoolManager-এর জন্য পপ-আপ
  চালু করে আবার চেষ্টা করুন।
