# প্রিন্ট ও আইডি কার্ড

SchoolManager দিয়ে শিক্ষার্থী ও কর্মীদের **আইডি কার্ড** ছাপা যায়। কার্ডের নকশা একবার
বানাতে হয়। তারপর একজন, কয়েকজন বা পুরো ক্লাসের কার্ড ছাপা যায়। যা-ই ছাপা হয়, সব
লেখা থাকে। তাই পরে আবার ছাপা যায়, আর হারিয়ে যাওয়া কার্ড বাতিলও করা যায়।

## কে কী করতে পারেন

| ভূমিকা     | কী করতে পারেন                                                        |
| ---------- | -------------------------------------------------------------------- |
| অ্যাডমিন   | সবকিছু: কার্ডের নকশা, প্রিন্টার যোগ, প্রিন্ট, ইতিহাস দেখা, কার্ড বাতিল |
| হিসাবরক্ষক | কার্ড প্রিন্ট ও আবার প্রিন্ট                                         |
| নির্বাহী   | প্রিন্টের ইতিহাস দেখা                                                |

**কর্মীর** কার্ড ছাপতে হলে কর্মীদের এইচআর রেকর্ড দেখার অনুমতিও লাগে।

## ৫ মিনিটে প্রথম আইডি কার্ড

1. **সেটিংস → প্রিন্টার**-এ গিয়ে যে প্রিন্টারে ছাপবেন সেটি যোগ করুন
   ([কেন জরুরি](printers-and-calibration.md#কেন-প্রিন্টার-আমাকে-নিজে-বেছে-নিতে-হয়))।
2. **প্রশাসন → প্রিন্ট টেমপ্লেট**-এ গিয়ে **নতুন টেমপ্লেট** চাপুন। তৈরি নকশা থেকে একটি
   বেছে নিন ([আরও](templates.md#তৈরি-নকশা-থেকে-টেমপ্লেট-বানান))।
3. **প্রকাশ করুন** চাপুন। জিজ্ঞেস করলে এটিকে **ডিফল্ট** করুন।
4. একজন শিক্ষার্থীকে খুলুন, **ডকুমেন্ট** ট্যাবে গিয়ে **আইডি কার্ড প্রিন্ট** চাপুন
   ([আরও](printing-id-cards.md#একটি-কার্ড-ছাপুন))।
5. প্রিভিউতে কার্ড দেখুন, আপনার প্রিন্টার বেছে নিন, **প্রিন্ট** চাপুন।
6. কার্ড বের হলে জিজ্ঞেস করবে **কার্ডগুলো কি ঠিকমতো ছাপা হয়েছে?** — উত্তর দিন।
