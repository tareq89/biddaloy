# ডিজাইনারের গাইড: Illustrator, Inkscape, Affinity বা Figma-তে ছবি আঁকা

এই পাতা তাঁর জন্য, যিনি কার্ডের ছবি আঁকেন। এটি মেনে চললে স্কুলকে একটি SVG ফাইল দিলেই
তারা এক ধাপে ইমপোর্ট করে নিতে পারবে।

## কীভাবে কাজ করে

আপনি আঁকবেন **পেছনের ছবি** (রং, লোগো, বর্ডার, স্থায়ী লেখা)। যেখানে নাম, শ্রেণি বা ছবি
বসবে, সেখানে লিখবেন একটি **প্লেসহোল্ডার**, যেমন `{{student.name}}`। SchoolManager প্রতিটি
প্লেসহোল্ডারকে বদলানো যায় এমন ফিল্ডে পরিণত করে, আর ছবি থেকে সেই লেখা সরিয়ে দেয়। তাই কিছুই
দুবার ছাপা হয় না।

## ১. ডিজাইন কিট দিয়ে শুরু করুন

স্কুলকে বলুন: **টেমপ্লেট → আপনার টেমপ্লেট → ফাইল → ডিজাইন কিট ডাউনলোড** চাপতে। দুটি ফাইল
পাবেন:

- `design-kit.svg` — ঠিক কার্ডের মাপের খালি আর্টবোর্ড, তিনটি স্তরসহ: **guides**, **artwork**
  আর **fields**।
- `design-kit-README.txt` — এই নির্দেশনার সংক্ষিপ্ত রূপ।

**artwork** স্তরের ভেতরে আঁকুন। **fields** স্তরে প্রতিটি ফিল্ডের জন্য একটি নমুনা `{{field}}`
লেখা আছে। যেগুলো লাগবে, কপি করে নিন।

## ২. মাপ ও দিক

মাপ মিলিমিটারে। কার্ডের সঙ্গে মেলে এমন আর্টবোর্ড নিন।

| কার্ড             | চওড়া × লম্বা  | দিক   |
| ----------------- | -------------- | ----- |
| CR80 পোর্ট্রেট    | ৫৪ × ৮৫.৬ মিমি | লম্বা |
| CR80 ল্যান্ডস্কেপ | ৮৫.৬ × ৫৪ মিমি | চওড়া |

আর্টবোর্ডের আকার আলাদা হলে ইমপোর্টের সময় সতর্কবার্তা আসবে, যেমন "আপনার আর্টবোর্ড ৬০×৯০
মিমি। এই টেমপ্লেট ৫৪×৮৫.৬ মিমি"।

## ৩. নিরাপদ এলাকা ও ব্লিড

- **নিরাপদ এলাকা: ৩ মিমি।** নাম, ছবি ও লোগো প্রতিটি কিনারা থেকে অন্তত ৩ মিমি ভেতরে রাখুন।
  প্রিন্টার কিনারার একটু কেটে ফেলতে পারে।
- **ব্লিড।** রং কিনারা পর্যন্ত গেলে আর্টওয়ার্কে রংটি কিনারার একটু বাইরে পর্যন্ত টেনে দিন।
  ঘরোয়া ও অফিস প্রিন্টার একদম কিনারা পর্যন্ত ছাপতে পারে না, তাই স্কুল সরু সাদা ধার দেখতে
  পেতে পারে। কার্ড প্রিন্টার পারে।

## ৪. লেখা: স্থায়ী লেখা আউটলাইন করুন, ফিল্ড থাকুক লাইভ

- সব **স্থায়ী লেখা** (যেমন স্কুলের নাম) **আউটলাইন** করুন (আকারে রূপান্তর)। তাহলে সব
  কম্পিউটারে একই রকম দেখাবে।
- প্রতিটি `{{field}}` **সাধারণ, লাইভ লেখা** হিসেবে রাখুন, আর **প্রতিটি ফিল্ড নিজের আলাদা
  টেক্সট বক্সে**। একই বক্সে অন্য শব্দ রাখবেন না: `নাম: {{student.name}}` ইমপোর্ট হবে না।
- প্লেসহোল্ডারে যে ফন্ট, মাপ, রং ও সারিবদ্ধতা চান তা দিন। ইমপোর্টে সেগুলো কপি হয়।

## ৬. এক্সপোর্ট সেটিংস

আগে **guides** স্তর মুছে ফেলুন। তারপর SVG হিসেবে এক্সপোর্ট করুন।

**Illustrator** — File → Save As → SVG, তারপর:

- SVG Profiles: **SVG 1.1**
- Styling: **Internal CSS**
- Fonts, Type: **SVG**। (আগে স্থায়ী লেখা আউটলাইন করুন; `{{field}}` বক্স লাইভ লেখা থাকবে।)
- Images: **Embed**
- Decimal places: **3**
- **Responsive: বন্ধ**

**Inkscape** — **Plain SVG** হিসেবে সংরক্ষণ করুন।

**Affinity Designer** — Export → SVG। শুধু স্থায়ী লেখার জন্য "Export text as curves" চালু করুন;
`{{field}}` লেখা লেখাই থাকুক।

**Figma** — SVG হিসেবে এক্সপোর্ট করুন। স্থায়ী লেখা আউটলাইন করুন, আর `{{field}}` টেক্সট
লেয়ারগুলো টেক্সটই রাখুন।

## ৭. ইমপোর্টের সতর্কবার্তার মানে

| সতর্কবার্তা                                    | মানে ও কী করবেন                                                                                    |
| ---------------------------------------------- | -------------------------------------------------------------------------------------------------- |
| "_{{something}} এই ডকুমেন্টের কোনো ফিল্ড নয়_" | নামটি এই কার্ডের জন্য ভুল। এটি ছবিতেই থেকে যায়। ওপরের তালিকা দেখে বানান ঠিক করুন।                 |
| "_ফন্ট নেই, Biddaloy Sans ব্যবহার হচ্ছে_"      | স্কুল ওই ফন্ট আপলোড করেনি। তাদের **ফাইল → ফন্ট**-এ আপলোড করতে বলুন, বা তাদের ফন্ট ব্যবহার করুন।    |
| "_আপনার আর্টবোর্ড … মি.মি._"                   | আর্টবোর্ডের আকার কার্ডের আকারের মতো নয়। ঠিক মাপে আবার এক্সপোর্ট করুন।                             |
| "_ফিল্ডের সঙ্গে অন্য শব্দ মিশে আছে_"           | প্রতিটি ফিল্ড আলাদা টেক্সট বক্সে রাখুন।                                                            |
| "কোনো লেখা পাওয়া যায়নি"                      | ফাইলটি শুধু ব্যাকগ্রাউন্ড হিসেবে ব্যবহার হবে। প্লেসহোল্ডারগুলো লাইভ লেখা কি না দেখুন, আউটলাইন নয়। |
