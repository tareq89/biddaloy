# ড্যাশবোর্ড

প্রতিটি ভূমিকার জন্য একটি ড্যাশবোর্ড আছে, যা আজ কী দেখা দরকার তা জানায়। প্রতিটি উইজেটের মানে, কীভাবে নিজের মতো সাজাবেন এবং সতর্কতা ও নোটিফিকেশন কীভাবে কাজ করে তা জানুন।

- [ড্যাশবোর্ডে আজকের কাজ দেখা](dashboard.md) — প্রথম পাতা, আজকের সারাংশ, ভূমিকা অনুযায়ী ড্যাশবোর্ড।
- [উইজেটগুলোর মানে বোঝা](widgets.md) — প্রতিটি উইজেট কী বলে আর কী করবেন।
- [ড্যাশবোর্ড নিজের মতো সাজানো](customise.md) — উইজেট দেখান, লুকান, সাজান; স্কুলের ড্যাশবোর্ড সেটিংস; মাসিক সভার রিপোর্ট।
- [সতর্কতা দেখা ও মেটানো](alerts.md) — করণীয়, পরে মনে করান, সকালের সারসংক্ষেপ, পুশ।
- [SchoolManager-এ স্বাগতম](../README.md) — পুরো গাইড কোথা থেকে শুরু করবেন।
