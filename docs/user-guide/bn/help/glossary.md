# শব্দের তালিকা

এই গাইডে যেসব শব্দ বারবার আসে, তার সহজ অর্থ ও উদাহরণ এখানে। কোনো শব্দ বুঝতে না পারলে এখানে খুঁজুন। শব্দগুলোর বানান স্ক্রিনের লেখার সাথে মেলানো।

## স্কুলের শব্দ <a href="#school" id="school"></a>

| শব্দ                                                                                    | অর্থ                                                                                    | উদাহরণ                                                 |
| --------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------- | ------------------------------------------------------ |
| <a id="section"></a>**শাখা**                                                            | একটি শ্রেণির ভাগ। একই শ্রেণির শিক্ষার্থীরা শাখায় ভাগ হয়ে বসে।                         | ষষ্ঠ শ্রেণির খ শাখা।                                   |
| <a id="class"></a>**শ্রেণি**                                                            | শিক্ষার্থীরা যে স্তরে পড়ে।                                                             | ষষ্ঠ শ্রেণি।                                           |
| <a id="shift"></a>**শিফট**                                                              | স্কুল যে সময়ের পালায় চলে, যেমন সকালের পালা বা দিনের পালা।                             | সকালের শিফটে ষষ্ঠ শ্রেণির ক ও খ শাখা।                  |
| <a id="version"></a>**ভার্সন**                                                          | শ্রেণি যে মাধ্যমে পড়ানো হয়, যেমন বাংলা বা ইংরেজি।                                     | ষষ্ঠ শ্রেণি, বাংলা ভার্সন।                             |
| <a id="group"></a>**গ্রুপ**                                                             | উচ্চ শ্রেণির বিষয়ের ধারা, যেমন বিজ্ঞান, ব্যবসায় শিক্ষা বা মানবিক।                     | নবম শ্রেণি, বিজ্ঞান গ্রুপ।                             |
| <a id="academic-year"></a>**শিক্ষাবর্ষ**                                                | স্কুলের এক বছরের পড়াশোনার সময়। ভর্তি, ফি আর ফলাফল এই বছর ধরে চলে।                     | ২০২৬ শিক্ষাবর্ষ।                                       |
| <a id="roll-number"></a>**রোল নম্বর**                                                   | শাখায় একজন শিক্ষার্থীর ক্রমিক নম্বর। হাজিরার খাতায় এই নম্বর অনুযায়ী নাম সাজানো থাকে। | রোল ১২।                                                |
| <a id="role"></a>**ভূমিকা**                                                             | স্কুলের সিস্টেমে আপনার কাজের পরিচয়। ভূমিকা ঠিক করে আপনি কী দেখতে ও করতে পারবেন।        | শিক্ষক, হিসাবরক্ষক, অ্যাডমিন।                          |
| <a id="dashboard"></a>**ড্যাশবোর্ড**                                                    | সাইন ইন করার পর প্রথম পাতা। আপনার সবচেয়ে জরুরি কাজগুলো এখানে কার্ড হয়ে থাকে।          | **উপস্থিতি নেওয়া বাকি** কার্ড।                        |
| <a id="fee-structure"></a>**ফি কাঠামো**                                                 | কোন শ্রেণির শিক্ষার্থী কোন খাতে কত টাকা দেবে, তার তালিকা।                               | ষষ্ঠ শ্রেণির মাসিক বেতন।                               |
| <a id="dues"></a>**বকেয়া**                                                             | একজন শিক্ষার্থীর যে টাকা এখনো দেওয়া হয়নি।                                             | জানুয়ারির বেতন বাকি।                                  |
| <a id="invoice"></a>**ফির বিল**                                                         | একজন শিক্ষার্থীর জন্য তৈরি ফির বিল। কত টাকা, কোন খাতে, কবে পর্যন্ত, তা এতে লেখা থাকে।   | জানুয়ারি মাসের বেতনের ফির বিল।                        |
| <a id="payment"></a>**পেমেন্ট**                                                         | স্কুল যে টাকা নিয়েছে, তার রেকর্ড।                                                      | নগদে ৫০০ টাকা নেওয়া।                                  |
| <a id="receipt"></a>**রসিদ**                                                            | টাকা নেওয়ার পর পাওয়া প্রমাণপত্র।                                                      | বেতনের রসিদ।                                           |
| <a id="fine"></a>**জরিমানা**                                                            | নিয়ম ভাঙলে যে টাকা ধরা হয়, যেমন বিনা কারণে অনুপস্থিতি।                                | জরিমানার নিয়ম অনুযায়ী ২০ টাকা।                       |
| <a id="guardian"></a>**অভিভাবক**                                                        | শিক্ষার্থীর বাবা, মা বা যিনি দেখাশোনা করেন। স্কুল তাঁর সাথে যোগাযোগ করে।                | শিক্ষার্থীর মা।                                        |
| <a id="attendance-register"></a>**হাজিরার খাতা**                                        | একটি শাখার একদিনের হাজিরা। প্রতি শাখায় প্রতিদিন একটি।                                  | ষষ্ঠ শ্রেণির খ শাখার আজকের খাতা।                       |
| <a id="monthly-register"></a>[**উপস্থিতির খাতা**](../attendance/attendance-register.md) | পুরো মাসের হাজিরা একসাথে দেখার পাতা।                                                    | জানুয়ারি মাসের উপস্থিতির খাতা।                        |
| <a id="draft"></a>**খসড়া**                                                             | যা সিস্টেমে আছে, কিন্তু এখনো শেষ হিসাবে ধরা হয়নি।                                      | জমা দেওয়ার পর শাখার পাশে **খসড়া** লেখা।              |
| <a id="leave"></a>**ছুটি**                                                              | শিক্ষার্থী বা কর্মী জানিয়ে অনুপস্থিত থাকলে যে অবস্থা।                                  | আগে থেকে জানানো ছুটি।                                  |
| <a id="report"></a>**প্রতিবেদন**                                                        | সিস্টেমের তথ্য একসাথে সাজিয়ে দেখার পাতা।                                               | উপস্থিতি প্রতিবেদন।                                    |
| <a id="teacher-assignment"></a>**শিক্ষকের দায়িত্ব**                                    | কোন শিক্ষক কোন শাখা ও বিষয় পড়ান, তার তালিকা। এটি না থাকলে শিক্ষক সেই শাখা দেখেন না।   | রহিম স্যার: ষষ্ঠ শ্রেণির খ শাখা, গণিত।                 |
| <a id="calendar"></a>**ক্যালেন্ডার**                                                    | স্কুলের ছুটি, পরীক্ষা আর অনুষ্ঠানের তারিখ।                                              | শুক্রবার সাপ্তাহিক ছুটি।                               |
| <a id="palette"></a>খোঁজার ঘর (Ctrl+K)                                                  | যেকোনো পাতা নাম লিখে খুঁজে নেওয়ার জায়গা। কি-বোর্ডে Ctrl আর K একসাথে চাপলে খোলে।       | "উপস্থিতি" লিখে পাতা খোলা।                             |
| <a id="offline"></a>**অফলাইন**                                                          | ইন্টারনেট ছাড়া অবস্থা।                                                                 | মাঠে গিয়ে নেটওয়ার্ক না পাওয়া।                       |
| <a id="sync"></a>**সিঙ্ক**                                                              | ডিভাইসে রাখা কাজ ইন্টারনেট ফিরলে স্কুলের সিস্টেমে পাঠানো।                               | **ডিভাইসে সংরক্ষিত হয়েছে — অনলাইনে ফিরলে সিঙ্ক হবে**। |
| <a id="sign-in"></a>**সাইন ইন**                                                         | আপনার নাম ও পাসওয়ার্ড দিয়ে সিস্টেমে ঢোকা।                                             | ফোন নম্বর ও পাসওয়ার্ড দিয়ে সাইন ইন।                  |

## তিনটি অবস্থা: কাজটি কোথায় পৌঁছেছে <a href="#states" id="states"></a>

যে পাতায় কিছু সংরক্ষণ হয়, সেখানে এই তিনটি নাম সবসময় একই অর্থে ব্যবহার হয়।

| অবস্থা                       | অর্থ                                                                           |
| ---------------------------- | ------------------------------------------------------------------------------ |
| **শুধু স্ক্রিনে বদলেছে**     | নামের পাশে চিহ্ন আছে, কিন্তু কাজটি এখনো জমা দেননি। কিছুই সিস্টেমে যায়নি।      |
| **এই ডিভাইসে সংরক্ষিত**      | কাজটি আপনার ফোন বা কম্পিউটারে রাখা আছে। ইন্টারনেট ফিরলে স্কুলের সিস্টেমে যাবে। |
| **স্কুলের সিস্টেমে পৌঁছেছে** | কাজটি স্কুলের সিস্টেমে জমা হয়েছে। অন্য ডিভাইসে বা অন্য কেউ খুললেও দেখবেন।     |

## খাতা ও রসিদের নাম <a href="#nouns" id="nouns"></a>

প্রতিটি পাতা তার জিনিসটিকে একটি নামে ডাকে। সেই নামই পুরো পাতায় চলে।

| পাতার অংশ | নাম                                                        |
| --------- | ---------------------------------------------------------- |
| উপস্থিতি  | **হাজিরার খাতা**                                           |
| উপস্থিতি  | [**উপস্থিতির খাতা**](../attendance/attendance-register.md) |
| ফি        | **ফির বিল**                                                |
| ফি        | **বেতনের রসিদ**                                            |
| ফি        | **শিক্ষার্থীর বকেয়া**                                     |

নতুন পাতা লেখা হলে তার নামও এখানে যোগ হয়।
