## তিনটি অবস্থা: কাজটি কোথায় পৌঁছেছে <a href="#states" id="states"></a>

যে পাতায় কিছু সংরক্ষণ হয়, সেখানে এই তিনটি নাম সবসময় একই অর্থে ব্যবহার হয়।

| অবস্থা | অর্থ |
| --- | --- |
| **শুধু স্ক্রিনে বদলেছে** | নামের পাশে চিহ্ন আছে, কিন্তু কাজটি এখনো জমা দেননি। কিছুই সিস্টেমে যায়নি। |
| **এই ডিভাইসে সংরক্ষিত** | কাজটি আপনার ফোন বা কম্পিউটারে রাখা আছে। ইন্টারনেট ফিরলে স্কুলের সিস্টেমে যাবে। |
| **স্কুলের সিস্টেমে পৌঁছেছে** | কাজটি স্কুলের সিস্টেমে জমা হয়েছে। অন্য ডিভাইসে বা অন্য কেউ খুললেও দেখবেন। |

| <a id="audit-log"></a>[**কার্যক্রমের রেকর্ড**](../administration/audit-logs.md) | স্কুলে কে, কখন, কী তৈরি, বদল বা মুছেছেন, তার তালিকা। শুধু দেখা যায়, বদলানো যায় না। | কে কাল একটি পেমেন্ট বাতিল করেছেন। |
