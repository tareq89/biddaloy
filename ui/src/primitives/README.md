# `primitives/` — vendored shadcn/ui output

Generated by the shadcn CLI, wired up in **[8.1.3]**. Treat everything here as
vendored: regenerate it, never hand-edit it.

It is deliberately **absent from the package's `exports` map**, so no SPA can
import a primitive directly. Customisation belongs in a wrapper under
`../components/`, which is the only public surface — that is what lets one
design change reach four apps instead of being copy-pasted into each.

`scripts/check-exports.mjs` fails the build if this directory ever becomes
publicly exported.
